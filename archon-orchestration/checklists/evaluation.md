# Critic and Rank Checklist

- [ ] Critic covers every usable candidate.
- [ ] Each candidate has strengths and weaknesses, not just a score.
- [ ] Missing assumptions and risks are explicit.
- [ ] Unique insights/reusable parts are extracted before filtering.
- [ ] Verification evidence is attached with scope/limitations when available.
- [ ] Ranker uses the frozen task rather than post-hoc requirements.
- [ ] Ranking has reasons, confidence, and unresolved disagreements.
- [ ] Top K full candidates are selected.
- [ ] Useful lower-ranked insights are preserved for Fuser.
- [ ] Extra evaluator is used only if escalation criteria are met.
