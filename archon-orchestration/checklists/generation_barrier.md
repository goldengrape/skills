# Generation Barrier Checklist

Use before Critique.

- [ ] Every scheduled Generator is terminal: completed / failed / cancelled / contaminated.
- [ ] Every completed Generator has a stable artifact reference.
- [ ] Failed/cancelled/contaminated Generators are explicitly recorded.
- [ ] No candidate is falsely treated as independent after cross-reading another candidate.
- [ ] At least the policy-required candidate quorum is available.
- [ ] Replacement budget, if used, is recorded.
- [ ] Candidate IDs are stable for evaluation.
- [ ] Provider/model identity is removed from evaluation input when practical.
