# Session Record

File path:

```text
sessions/day-N-session.md
```

# Required Sections

````markdown
# Day N Session

## Input State
Briefly summarize current state before learning.

## Covered
Topics actually covered.

## Learner Answers
Representative answers or summaries of answers.

## Assessment
Estimated score, strengths, weaknesses.

## Misconceptions
New, repeated, and resolved misconceptions.

## State Updates Required
Files that must be updated.

## Next Action
The next session instruction.
````

# Rule

Session records are evidence. They should record what the learner demonstrated, not just what was taught.
