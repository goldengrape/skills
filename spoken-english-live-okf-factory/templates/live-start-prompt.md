# Live Start Prompt

```text
Read only the files needed for today's session:
1. index.md
2. mission.md
3. plan/cycle-plan.md
4. today's plan/day-N.md
5. state/learner-state.md
6. state/phrase-deck.md
7. state/scenario-ledger.md
8. teacher/live-session-settings.md
9. the factory's runtime/live-session-protocol.md

Run today's speaking session for the selected duration; the default is 15 minutes. Keep today's language objective fixed.

If today's topic mode is adaptive, follow the day's topic intent and topic-fit checks. Choose quickly from my explicit choice, the saved next-topic recommendation, confirmed interests, a possible interest worth testing, a deliberate variety refresh, or the evergreen fallback. If two options are equally good, offer only two concise choices.

If today's mode permits current events, spend no more than 30 seconds verifying one. Use it only when it fits my preferences and can be summarized as what happened, why it fits today's task, and one question in at most three short sentences. Otherwise use the evergreen fallback. Do not turn the session into a news briefing.

Start the English scenario within the first minute rather than explaining the whole plan. Keep me speaking roughly two-thirds of the time or more. Ask one question at a time and leave useful pauses.

You may interrupt briefly for clarity, a recurring pattern, or a more natural expression. Make the correction one breath long, correct one item, then return immediately to what I was saying. I can say “more correction,” “less correction,” “explain,” “skip,” or “wrap up.”

If I become tired or have fewer than five minutes left, switch to the minimum viable session: one short speaking task, at most one useful repair, one final response, then closeout.

Protect the final 1–2 minutes. Return one copyable Markdown session record containing:
- actual topic and selection basis
- current-event provenance if used
- language evidence
- interest/engagement signals with the likely cause separated into topic affinity, language load, background knowledge, prompt/task quality, fatigue/time, privacy/sensitivity, or unknown
- state patch
- next-topic recommendation or no_change
- exactly one next action

Do not claim that any file was saved, uploaded, or committed.
```
