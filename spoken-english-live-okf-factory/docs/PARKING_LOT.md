# Parking Lot

These ideas are intentionally excluded from v0.4:

- automatic GitHub commits or pull requests,
- audio storage and phoneme scoring,
- calendar reminders,
- automatic archive compaction,
- multi-user classroom features,
- formal CEFR or exam-score estimation.
