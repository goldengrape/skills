# DP-006 — Rollover Cycle

## Inputs

- original cycle plan;
- all completed session records;
- explicit skipped or partial-session records;
- canonical learner state;
- phrase deck;
- scenario ledger.

If records are missing, produce a partial-cycle review and name the gap. Do not infer completion.

## Step 1 — Build an Evidence Table

| Item | Status | Evidence refs | Confidence |
|---|---|---|---|
| scenario performance | improved / unchanged / mixed / unknown | session IDs | high / medium / low |
| phrase retrieval | learning / stable / not tested | session IDs | high / medium / low |
| recurring pattern | active / improved / uncertain / retired | session IDs | high / medium / low |
| fluency or interaction | improved / unchanged / mixed / unknown | session IDs | high / medium / low |
| fatigue or duration | sustainable / tiring / unknown | session IDs or learner report | high / medium / low |
| topic engagement | confirmed / possible / mixed / low-engagement candidate / avoided / unknown | session IDs plus affinity/load classification | high / medium / low |
| topic diversity | balanced / repetitive_by_design / repetitive_without_reason / unknown | recent-topic history | high / medium / low |
| adaptive-topic effectiveness | helped / neutral / disrupted / not tested | session IDs | high / medium / low |
| current-event suitability | useful / too complex / unsuitable / not tested | session IDs | high / medium / low |

Skipped days are attendance facts, not evidence of inability or topic dislike.

## Step 2 — Make Four Decisions

State explicitly for language targets and topic strategy:

- **continue:** still valuable and not yet stable;
- **change:** useful, but task, cue, pressure, topic mix, or explanation should change;
- **retire:** stable or no longer useful enough for active use, with evidence;
- **test next:** uncertain, unobserved, or contradictory.

Default language thresholds:

- retire a phrase only after spontaneous appropriate use in at least two sessions or three varied contexts;
- retire an error target only after at least two later opportunities without recurrence, including one transfer context;
- do not declare relapse from one isolated later occurrence.

Default topic thresholds:

- carry a topic as confirmed when explicitly chosen or supported by repeated engagement;
- keep one-off positive signals as `possible`;
- do not retire or downgrade a topic from one tired, shortened, difficult, or sensitive session;
- preserve variety: a confirmed interest may recur, but should not occupy more than three sessions in a normal seven-day guided-adaptive cycle unless the learner requests a thematic cycle;
- reuse a topic only with a changed language function, pressure, role, or perspective;
- include one `test_possible` or `refresh_variety` slot when evidence and learner load permit;
- do not downgrade interest when the observed problem was language load, knowledge load, prompt quality, fatigue, or privacy;
- current events remain optional and should be reduced or disabled if they repeatedly consume speaking time or create excessive background burden.

When evidence is thin, choose `test next`.

## Step 3 — Propose the Next Cycle

Recommend:

- 3 or 7 days;
- daily duration;
- one scenario/communicative target;
- one fluency/discourse target;
- one language-repair target;
- topic policy, anchored/adaptive ratio, and adaptive intent mix (`deepen_confirmed`, `test_possible`, `refresh_variety`);
- confirmed interests to reuse;
- possible interests to test;
- avoided or retired topics;
- current-event setting and category preferences;
- carry-over phrases and retests.

Every substantive decision must cite evidence or an explicit current instruction.

## 🔴 CHECKPOINT — Learner Choice Before a Materially New Direction

Stop at the proposal when:

- the primary goal or scenario family changes;
- recommended duration changes;
- the proposal chooses 3 instead of 7 days, or vice versa, without explicit instruction;
- current events are newly enabled, sensitive categories are introduced, or exclusions would change;
- a single thematic interest would dominate most of the next cycle;
- two next-cycle directions are equally supported.

Present options and evidence briefly. The next factory run begins only after the learner chooses or explicitly delegates the choice.

## Output

Create:

1. `review/cycle-review.md`;
2. `review/next-cycle-proposal.md`;
3. a compact carry-over snapshot compatible with DP-001.

The proposal does not edit the completed cycle's blueprint.

## Failure Rules

| Trigger | Required response |
|---|---|
| Proposal has no evidence references | Reject and add session/state references. |
| More than three primary language targets | Reduce scope before presentation. |
| Every old target is carried forward | Re-evaluate stable, low-value, and untested items. |
| One topic signal is promoted to confirmed without explicit preference | Downgrade to possible. |
| Engagement evidence is confounded by language, knowledge, prompt, fatigue, or privacy load | Preserve interest state and change task/support instead. |
| One interest dominates the proposed guided-adaptive cycle without learner request | Add a test or variety slot and vary language functions. |
| A tired session is used as evidence of dislike | Remove the inference and preserve uncertainty. |
| Current events are enabled without category and verification policy | Add policy or keep them disabled. |
| Skipped day is described as failed performance | Correct it to skipped or unknown. |
| Stable/retired claim lacks threshold evidence | Downgrade to learning, improved, or test next. |
| Next direction materially changes without confirmation | Stop at the checkpoint. |
