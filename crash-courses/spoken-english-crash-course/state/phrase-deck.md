# Cycle 1 Phrase Deck

Update status only from session evidence: `new` → `learning` after successful supported use; `stable` after independent use across separate contexts.

| Phrase | Use when | Status | Next review condition |
|---|---|---|---|
| `First..., then..., and after that...` | sequencing a process | new | retrieve during Day 2 without reading the full model |
| `The reason is that...` | explaining a choice | new | use in a follow-up answer |
| `Before I trust the answer, I...` | adding a quality check | new | use during Day 2 or another tool workflow |
| `Compared with..., ...` | starting a direct comparison | new | use with two options on Day 3 |
| `One advantage is..., but the main trade-off is...` | balancing benefit and cost | new | reuse on an adaptive topic |
