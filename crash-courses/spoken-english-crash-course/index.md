# Spoken English Crash Course — Week 1

This pack is a seven-day speaking cycle for an estimated B1–B2 learner. The default session is 15 minutes; if time and energy allow, use the optional extension in the daily plan to reach about 20 minutes.

## Reading order for today's session

1. Read [mission.md](mission.md).
2. Read [plan/cycle-plan.md](plan/cycle-plan.md) once at the start of the week.
3. Open today's file in `plan/`.
4. Read `state/learner-state.md`, `state/phrase-deck.md`, and `state/scenario-ledger.md`.
5. Apply `teacher/live-session-settings.md` during ChatGPT Live.
6. After speaking, copy `sessions/session-template.md`, save the record, and update the three state files.

## Completion rule

A day is complete only after the speaking task, one repair-and-reuse attempt, the session record, the state patch, and exactly one next action are recorded. A shortened session still counts when the minimum viable version is completed and marked accurately.
