# Must-Know List

## A Topics

1. 定位诊断先于病因诊断。
2. UMN/LMN 是运动定位第一分叉。
3. 偏瘫题必须检查皮层体征和脑神经体征。
4. 感觉平面强烈提示脊髓。
5. 感觉分离帮助判断后索、脊髓丘脑束或半切。
6. 同侧脑神经体征 + 对侧长束体征提示脑干。
7. 失语、忽视、偏盲是半球定位高价值线索。
8. 共济失调和肌无力要分开。
9. 根、丛、神经、NMJ、肌肉按分布、感觉、反射和波动性区分。
10. 考试答案要写定位、证据、排除理由。

## Red Flags for Wrong Reasoning

- 只写病名，不写解剖位置。
- 只根据一个肢体体征作答。
- 忽略同侧/对侧关系。
- 把周围定位和脊髓定位混在一起。
