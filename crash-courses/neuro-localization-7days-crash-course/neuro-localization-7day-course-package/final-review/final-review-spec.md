# Final Review Specification

## Inputs

Reads L0-L4 only: resources, schemas, modules, assessment events, and state files. It does not rewrite earlier modules.

## Outputs

- compressed notes
- must-know list
- answer templates
- mock exam
- retest plan based on unresolved misconceptions

## Selection Rule

Prioritize unresolved A-topic misconceptions and blind/barehand failures.
