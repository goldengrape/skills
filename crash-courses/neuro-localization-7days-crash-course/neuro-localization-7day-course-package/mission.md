# Mission

## Course Mission

7 天内建立一套可考试使用的神经定位诊断推理路径：

病史和查体线索 → 中枢/周围 → 神经轴层级 → 支持证据 → 排除理由 → 考试型定位表述。

## Learner

- 医学生，考前复习。
- 有基础神经解剖名词印象，但定位推理不稳定。
- 默认目标：稳定通过混合题型考试。

## Time Policy

- default: soft。每日 60 分钟是计划目标，不是硬限制。
- strict 模式只在学习者明确要求时启用。

## Out of Scope

- 不写完整神经病学疾病学讲义。
- 不做具体学校押题。
- 不用于真实患者诊疗。
