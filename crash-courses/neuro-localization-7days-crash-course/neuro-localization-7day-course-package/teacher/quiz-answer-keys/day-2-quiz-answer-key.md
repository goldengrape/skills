## Retrieval Expected Answer

UMN：肌张力高、腱反射活跃、Babinski 阳性、萎缩不明显。LMN：肌张力低、反射减弱、明显萎缩/束颤。

## Exam-Style Question Expected Answer

右侧上下肢 UMN 体征可来自左侧半球/内囊，也可来自脑干或脊髓；无失语不能排除半球，需查忽视/偏盲、脑神经交叉体征、感觉平面。

## Boundary / Misuse Check Expected Answer

高颈髓：四肢 UMN + 感觉平面/括约肌；多发周围神经病：远端对称感觉和反射减弱；NMJ：波动疲劳、感觉正常；肌病：近端无力、感觉正常。
