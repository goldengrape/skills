## Retrieval Expected Answer

根病看皮节/肌节/对应反射，单神经病看命名神经 territory，丛病跨多个根和多个神经。

## Exam-Style Question Expected Answer

手套袜套样麻木、双侧踝反射减弱、远端无力：远端对称周围多发神经病。

## Boundary / Misuse Check Expected Answer

根病可有放射痛、皮节分布和对应反射改变；单神经病符合某个命名神经支配区。
