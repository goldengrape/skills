## Retrieval Expected Answer

定位诊断是判断病灶的解剖层级和侧别；病因诊断是判断造成病灶的疾病机制或疾病名称。偏瘫不能直接写半球，因为脑干、内囊、脊髓等也可造成长束体征；需找皮层线索、脑神经交叉体征、感觉平面。

## Exam-Style Question Expected Answer

左侧 UMN 体征，定位到右侧锥体束通路、锥体交叉以上；尚需用失语/忽视/偏盲、脑神经、感觉平面继续细分。

## Boundary / Misuse Check Expected Answer

至少列出：皮层功能线索、同侧脑神经 + 对侧肢体交叉体征、感觉平面/括约肌。
