## Retrieval Expected Answer

失语是语言系统问题；构音障碍是发音执行问题，语言理解和内容可保留。

## Exam-Style Question Expected Answer

右利手表达困难、理解保留、右上肢无力：左优势半球额叶语言运动网络或邻近运动区/通路。

## Boundary / Misuse Check Expected Answer

失语定位到优势半球语言网络；构音障碍可来自脑干、周围神经、NMJ、肌肉等。
