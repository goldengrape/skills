## DAY5-CASE-A

```yaml
teacher_private:
  case_id: DAY5-CASE-A
  localization_conclusion: "左侧优势半球额下回/额叶-岛盖周围语言运动网络，兼及左侧运动皮层或邻近皮质下通路。"
  supporting_evidence:
    - 右利手患者多为左侧优势半球。
    - 表达不流利而理解相对保留支持 Broca 型/非流利性失语方向。
    - 右下部面瘫和右上肢无力支持左侧运动区或邻近通路。
  exclusion_reasoning:
    - 不应只写构音障碍，因为理解和语言输出模式提示失语。
    - 不优先写内囊孤立病变，因为内囊不能解释典型皮层语言表现。
  common_mistakes:
    - 把失语误作说话含糊。
    - 忽略优势半球。
    - 只写“脑梗”不写定位。
  score_points:
    - item: 定位层级
      points: 3
    - item: 支持证据
      points: 3
    - item: 排除理由
      points: 2
    - item: 需要补充的查体或病史
      points: 2
  remediation:
    - 先复述题干体征，不急着写病名。
    - 用“定位结论—支持证据—排除理由—补充线索”的四格格式重答一遍。
```

## DAY5-CASE-B

```yaml
teacher_private:
  case_id: DAY5-CASE-B
  localization_conclusion: "右侧小脑半球或小脑通路病变方向，而非右侧锥体束病变。"
  supporting_evidence:
    - 右手指鼻试验不准和步态不稳支持共济失调。
    - 肌力基本正常，不符合主要锥体束无力。
    - 无 Babinski 征，缺少 UMN 强证据。
  exclusion_reasoning:
    - 锥体束病变应更期待无力、反射亢进、病理征阳性。
    - 小脑体征常同侧表现，右侧肢体共济失调可指向右小脑。
  common_mistakes:
    - 把“走不稳”都归为无力。
    - 不查辨距不良、轮替运动、眼震。
    - 把小脑体征误写成周围神经病。
  score_points:
    - item: 定位层级
      points: 3
    - item: 支持证据
      points: 3
    - item: 排除理由
      points: 2
    - item: 需要补充的查体或病史
      points: 2
  remediation:
    - 先复述题干体征，不急着写病名。
    - 用“定位结论—支持证据—排除理由—补充线索”的四格格式重答一遍。
```
