## DAY2-CASE-A

```yaml
teacher_private:
  case_id: DAY2-CASE-A
  localization_conclusion: "胸髓层级脊髓病变，约 T10 附近或以上相关节段，需要结合感觉平面精确定位。"
  supporting_evidence:
    - 双下肢痉挛性无力、膝反射活跃支持双侧 UMN 受累。
    - T10 以下痛温觉下降提示感觉平面。
    - 双下肢受累重于上肢，符合胸髓而非颈髓。
  exclusion_reasoning:
    - 不支持单纯周围神经病，因为有痉挛和感觉平面。
    - 不优先定位肌病，因为肌病通常感觉正常、反射早期相对保留。
  common_mistakes:
    - 把“腿无力”直接写成周围神经病。
    - 漏掉感觉平面。
    - 只写脊髓，不写胸髓方向。
  score_points:
    - item: 定位层级
      points: 3
    - item: 支持证据
      points: 3
    - item: 排除理由
      points: 2
    - item: 需要补充的查体或病史
      points: 2
  remediation:
    - 先复述题干体征，不急着写病名。
    - 用“定位结论—支持证据—排除理由—补充线索”的四格格式重答一遍。
```

## DAY2-CASE-B

```yaml
teacher_private:
  case_id: DAY2-CASE-B
  localization_conclusion: "右上肢局灶性 LMN/周围运动单位层级受累，需在 C8/T1 神经根、下干/内侧束、尺神经或前角细胞之间区分。"
  supporting_evidence:
    - 第一骨间肌萎缩和手指外展无力提示下运动神经元或周围神经支配肌受累。
    - 腱反射减弱支持 LMN/周围而非 UMN。
    - 无 Babinski 征，不支持典型锥体束受累。
  exclusion_reasoning:
    - 不像单纯 UMN：UMN 应更常见肌张力增高、反射亢进、病理征阳性，早期明显肌萎缩不突出。
    - 不能只写“手无力”，要按分布判断根/丛/神经。
  common_mistakes:
    - 看到无力就写锥体束。
    - 忽略肌萎缩和反射减弱。
    - 不做根、丛、单神经分布区分。
  score_points:
    - item: 定位层级
      points: 3
    - item: 支持证据
      points: 3
    - item: 排除理由
      points: 2
    - item: 需要补充的查体或病史
      points: 2
  remediation:
    - 先复述题干体征，不急着写病名。
    - 用“定位结论—支持证据—排除理由—补充线索”的四格格式重答一遍。
```
