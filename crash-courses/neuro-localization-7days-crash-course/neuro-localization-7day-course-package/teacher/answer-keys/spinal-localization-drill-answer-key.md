## SPINAL-001

```yaml
teacher_private:
  case_id: SPINAL-001
  localization_conclusion: "脊髓横贯性或近似横贯性病变，约脐平面对应胸髓节段方向，需结合皮节进一步定位。"
  supporting_evidence:
    - 双下肢痉挛性无力提示双侧 UMN 通路受累。
    - 脐平面以下感觉下降是感觉平面。
    - 尿潴留提示脊髓/中枢通路受累。
  exclusion_reasoning:
    - 远端周围神经病通常是手套袜套样，反射减弱为主，不形成清楚躯干感觉平面。
  common_mistakes:
    - 把“以下感觉下降”写成周围神经病。
    - 未使用感觉平面定位。
  score_points:
    - item: 定位层级或侧别
      points: 4
    - item: 感觉/运动证据解释
      points: 3
    - item: 排除一个相近定位
      points: 2
    - item: 补充检查或查体
      points: 1
  remediation:
    - 复画脊髓横断面：后索、皮质脊髓束、脊髓丘脑束。
    - 将“感觉平面”和“手套袜套样分布”并列比较一次。
```

## SPINAL-002

```yaml
teacher_private:

  supporting_evidence:
```

## SPINAL-003

```yaml
teacher_private:
  case_id: SPINAL-003
  localization_conclusion: "左侧 Brown-Séquard 综合征/左侧半脊髓损害。"
  supporting_evidence:
    - 左下肢 UMN 无力和左深感觉下降指向左侧半脊髓。
    - 右侧痛温觉下降符合痛温觉交叉后在对侧上行。
  exclusion_reasoning:
    - 不是单纯外周神经损伤，因为同时有长束运动和感觉分离。
  common_mistakes:
```

## SPINAL-004

```yaml
teacher_private:
  case_id: SPINAL-004
  localization_conclusion: "前脊髓综合征方向，累及皮质脊髓束和脊髓丘脑束，后索相对保留。"
  supporting_evidence:
    - 双下肢无力提示运动束受累。
    - 痛温觉下降提示脊髓丘脑束受累。
    - 位置觉、振动觉相对保留提示后索未作为主要受累系统。
  exclusion_reasoning:
    - 不符合后索为主病变，因为后索感觉相对保留。
    - 不符合周围神经病，因为有急性双侧长束和括约肌线索。
  common_mistakes:
    - 把所有感觉下降都认为是后索。
    - 漏掉后索保留这一定位线索。
  score_points:
    - item: 定位层级或侧别
      points: 4
```

## SPINAL-005

```yaml
teacher_private:
  case_id: SPINAL-005
  localization_conclusion: "更倾向马尾受累，但需结合起病、对称性、肛门反射、球海绵体反射和影像。"
  supporting_evidence:
    - 不对称根性放射痛支持多根神经根/马尾。
    - 双下肢反射减弱支持 LMN/根性受累。
    - 鞍区感觉和排尿困难提示腰骶终末区域受累。
  exclusion_reasoning:
    - 圆锥病变常更早出现括约肌和鞍区症状，疼痛可较少且更对称；本题不对称根性痛和反射减弱更推马尾。
  common_mistakes:
    - 只看到排尿困难就写圆锥。
    - 没比较反射和根性疼痛。
  score_points:
```
