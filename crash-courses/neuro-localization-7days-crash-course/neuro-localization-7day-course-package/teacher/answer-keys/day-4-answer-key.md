## DAY4-CASE-A

```yaml
teacher_private:
  case_id: DAY4-CASE-A
  localization_conclusion: "右侧脑桥病变，累及 VI 相关结构和锥体束，形成交叉性脑干体征。"
  supporting_evidence:
    - 右眼外展受限提示右侧外展神经核/束或相关脑桥结构。
    - 左侧肢体无力和 Babinski 阳性提示右侧锥体束在交叉前受累。
    - 同侧脑神经体征加对侧长束体征是脑干定位强线索。
  exclusion_reasoning:
    - 不应定位到左侧大脑半球，因为右侧脑神经体征不能由左半球偏瘫简单解释。
    - 也不能只写周围 VI 神经病，因为有对侧 UMN 体征。
  common_mistakes:
    - 只根据左侧肢体无力写左侧半球。
    - 忽略外展受限的侧别。
    - 没写脑桥层级。
  score_points:
    - item: 定位层级
      points: 3
    - item: 支持证据
      points: 3
    - item: 排除理由
      points: 2
    - item: 需要补充的查体或病史
      points: 2
  remediation:
    - 先复述题干体征，不急着写病名。
    - 用“定位结论—支持证据—排除理由—补充线索”的四格格式重答一遍。
```

## DAY4-CASE-B

```yaml
teacher_private:
  case_id: DAY4-CASE-B
  localization_conclusion: "更支持左侧优势半球/皮质或皮质下锥体束受累，而不是脑干。"
  supporting_evidence:
    - 左侧肢体 UMN 体征提示右侧锥体束病变；但题干同时给出失语，通常指向优势半球皮层语言网络。
    - 没有同侧脑神经下运动神经元体征、眼球运动异常或交叉性组合。
  exclusion_reasoning:
    - 脑干定位需要脑神经体征与对侧长束体征的组合；单纯偏瘫加失语更符合半球。
    - 构音障碍不等于失语，题中若是真失语则是皮层线索。
  common_mistakes:
    - 把所有偏瘫都脑干化。
    - 把失语当成延髓构音障碍。
    - 没说明缺少交叉性体征。
  score_points:
    - item: 定位层级
      points: 3
    - item: 支持证据
      points: 3
    - item: 排除理由
      points: 2
    - item: 需要补充的查体或病史
      points: 2
  remediation:
    - 先复述题干体征，不急着写病名。
    - 用“定位结论—支持证据—排除理由—补充线索”的四格格式重答一遍。
```
