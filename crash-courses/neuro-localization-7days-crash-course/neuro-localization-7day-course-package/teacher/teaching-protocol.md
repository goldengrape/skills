# Teaching Protocol

1. Read state before teaching.
2. Ask the student-visible question.
3. Do not expose teacher-private material before the learner answers.
4. After the learner answers, compare the response with rubrics and answer material.
5. Update state and schedule retest when needed.

## Feedback Style

- First identify the strongest correct part.
- Then isolate one or two errors.
- Anchor feedback to source, rubric, or learner output evidence.
- End with a new retrieval or transfer prompt.
