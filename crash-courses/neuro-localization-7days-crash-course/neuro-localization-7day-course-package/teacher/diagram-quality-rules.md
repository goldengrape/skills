# Diagram Quality Rules

Check every diagram for: title, readable labels, correct directionality, side labels when relevant, legend when needed, and axis or coordinate labels if an axis-based graph is used.

For neuroanatomy maps, also check whether the diagram supports the localization decision rather than just looking decorative.
