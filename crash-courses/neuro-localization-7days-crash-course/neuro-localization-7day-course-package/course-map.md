# Course Map

## 一条主线

```text
体征 → 中枢/周围 → 神经轴层级 → 同侧/对侧关系 → 支持证据 → 排除理由 → 定位表述
```

## 神经轴定位层级

| 层级 | 高价值线索 | 常见考试问法 | 先排除什么 |
|---|---|---|---|
| 大脑半球皮层 | 失语、忽视、皮层感觉障碍、同向偏盲、癫痫发作 | 根据高级皮层体征定位脑叶或优势半球 | 不能解释同侧脑神经核性体征的答案 |
| 皮层下/内囊 | 纯运动或纯感觉偏瘫，皮层高级功能少 | 偏瘫很重但无失语/忽视 | 周围神经、单一神经根 |
| 脑干 | 同侧脑神经体征 + 对侧长束体征 | 交叉性体征定位中脑/脑桥/延髓 | 单纯大脑半球病变 |
| 小脑/前庭 | 共济失调、眼震、眩晕、意向性震颤 | 小脑半球、蚓部、前庭周围/中枢区分 | 锥体束性无力 |
| 脊髓 | 感觉平面、双侧长束体征、括约肌问题 | 半切、前索、中央、圆锥/马尾 | 多发周围神经病 |
| 神经根 | 根性疼痛、肌节 + 皮节分布、反射改变 | C5/L5/S1 等根定位 | 单一周围神经卡压 |
| 神经丛 | 不符合单根或单神经的片状运动感觉缺损 | 臂丛、腰骶丛定位 | 多发单神经病 |
| 周围神经 | 单神经支配区缺损 | 正中/尺/桡/腓总神经等 | 神经根病 |
| 神经肌接头 | 波动性、疲劳性、感觉正常 | 重症肌无力样题目定位 | 肌病、周围神经病 |
| 肌肉 | 近端为主、感觉正常、反射相对保留早期 | 肌病模式识别 | LMN 病变 |

## Course Dependency Policy

本课程包采用下三角依赖：`resources → schemas → modules → assessment → state → final-review → quality`。状态记录只消费学习事件，不反向修改讲义。

## Medical Boundary

病例均为教学模拟。真实患者情况必须由合格临床医生根据完整病史、查体和检查判断。
