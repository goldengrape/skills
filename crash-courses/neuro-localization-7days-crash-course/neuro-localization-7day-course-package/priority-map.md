# Priority Map

## A — Must Learn

| Topic | Why it matters | Common question form | Source evidence |
|---|---|---|---|
| 神经轴总定位 | 所有定位题的入口 | 给一组体征，问病灶在哪里 | SRC-001, SRC-002 |
| UMN vs LMN | 判断中枢/周围的第一分叉 | 肌张力、反射、病理反射、萎缩、束颤 | SRC-003, SRC-007 |
| 偏瘫/截瘫/四肢瘫定位 | 高频病例题主干 | 肢体分布 + 反射 + 感觉线索 | SRC-002, SRC-003 |
| 感觉平面和感觉分离 | 脊髓定位核心 | 半切、前索、中央综合征 | SRC-002, SRC-008 |
| 脑干交叉性体征 | 最容易错且考试价值高 | 同侧脑神经 + 对侧长束 | SRC-002, SRC-004 |
| 脑神经定位 | 连接脑干和周围神经 | 眼球运动、面瘫、吞咽构音 | SRC-003, SRC-004 |
| 皮层功能定位 | 区分皮层/皮层下 | 失语、忽视、偏盲 | SRC-002, SRC-004 |
| 周围定位模式 | 下运动神经元题高频 | 根、丛、神经、NMJ、肌肉 | SRC-006 |
| 定位答题模板 | 直接影响简答题分数 | 写定位结论和依据 | SRC-001, SRC-002 |

## B — Should Learn

| Topic | Why it helps | When to study | Source evidence |
|---|---|---|---|
| ACA/MCA/PCA 供血区 | 卒中题常与半球定位合并 | Day 5 后 | SRC-001, SRC-004 |

| 小脑 vs 前庭 | 共济失调、眩晕题常见 | Day 5 | SRC-003, SRC-004 |
| 肌病 vs NMJ | 周围定位末端分叉 | Day 6 | SRC-006 |
| 检查选择逻辑 | 定位后才考虑检查 | Day 7 简要 | SRC-001 |

## C — Can Skip or Only Recognize

| Topic | Reason for lower priority | Source evidence |
|---|---|---|
| 罕见脑干综合征全名 | 7 天复习性价比低，保留典型模式即可 | SRC-002 |
| 复杂核团细节 | 容易挤占病例推理训练 | SRC-004 |
| 高级影像判读 | 非本课程主线 | SRC-001 |
| 罕见遗传性神经病 | 当前考试目标不支持展开 | SRC-006 |

## Rule

A 类必须经过讲解、提取练习、Feynman 任务、病例迁移和误用识别。B 类做压缩讲解和选择性练习。C 类只识别名称和典型考试陷阱。
