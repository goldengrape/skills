# Glossary

| Term | 中文 | Exam Use | Minimal distinction |
|---|---|---|---|
| Localization diagnosis | 定位诊断 | 判断病灶解剖位置 | 不是直接写病因或病名 |
| Upper motor neuron | 上运动神经元 | 中枢锥体束相关体征 | 肌张力高、反射活跃、病理反射阳性 |
| Lower motor neuron | 下运动神经元 | 前角、根、神经相关体征 | 肌萎缩、束颤、反射减弱、肌张力低 |
| Long tract sign | 长束体征 | 提示中枢传导束受累 | Babinski、痉挛性瘫、感觉束受累 |
| Crossed findings | 交叉性体征 | 脑干定位核心 | 同侧脑神经 + 对侧肢体/感觉 |
| Sensory level | 感觉平面 | 脊髓定位核心 | 周围神经病通常无清楚躯干感觉平面 |
| Dissociated sensory loss | 感觉分离 | 判断束受累 | 痛温和深感觉不同步受损 |
| Aphasia | 失语 | 优势半球皮层定位 | 与构音障碍不同 |
| Neglect | 忽视 | 非优势顶叶常见线索 | 不是单纯视力下降 |
| Hemianopia | 偏盲 | 视路/枕叶/放射冠定位 | 与眼球运动障碍不同 |
| Radiculopathy | 神经根病 | 皮节/肌节/反射组合 | 常有根性疼痛 |
| Plexopathy | 神经丛病 | 跨多个根和周围神经 | 分布不符合单一根或单一神经 |
| Polyneuropathy | 多发周围神经病 | 长度依赖型感觉运动异常 | 常为手套袜套样 |
| Neuromuscular junction | 神经肌接头 | 疲劳性、波动性 | 感觉通常正常 |
| Myopathy | 肌病 | 近端肌无力为主 | 感觉正常，反射早期相对保留 |
