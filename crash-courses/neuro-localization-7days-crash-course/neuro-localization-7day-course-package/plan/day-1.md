# Day 1: 定位诊断总地图

## Today’s Goal

完成 定位诊断总地图 的定位推理训练。作答时先定位解剖层级，再说明证据，不急着写疾病名称。

## Low-Baseline Bridge

如果学生在 Recall 中把定位诊断写成病名，或把偏瘫侧别写反，先完成 `remediation/low-baseline-bridge.md` 的三道出口题，再进入病例练习。

## Why This Matters for the Exam

考试题常把多个体征放在一起。如果只凭一个关键词作答，容易把脑干写成半球、把脊髓写成周围神经、把肌病写成神经根病。

## Time Policy

```yaml
total_minutes: 60
time_policy: soft
new_A_topics_limit: 3
```

## 0-5 min — Recall

不用笔记回答：

1. 定位诊断和病因诊断有什么不同？
2. 今天主题中最重要的侧别或层级线索是什么？
3. 遇到不确定题目时，先排除哪一个常见误判？

## 5-10 min — Map

今天的位置：`course-map.md` → `神经轴总图、定位不是病名、中枢/周围第一分叉` → 病例作答 → 状态记录。

## 10-25 min — Core Explanation

本节只讲考试所需的最小定位规则。重点看：

- 体征来自哪个系统。
- 体征是否组合成一个神经轴层级。
- 侧别关系是同侧、对侧、双侧还是交叉。
- 有没有一个更简单的周围或中枢解释。

## 25-35 min — Feynman Task

学生提示：

```text
用自己的话向低年级同学解释：神经轴总图、定位不是病名、中枢/周围第一分叉 为什么能帮助定位？请用一个小病例说明。
```

## Diagram Cue

进入病例前，先打开 `assets/diagrams/index.md` 中对应图示，用 30 秒确认病灶层级和侧别关系。

## 35-45 min — Exam Practice

学生题目：

```text
一个患者突发右侧肢体无力，右侧 Babinski 阳性，没有明显肌萎缩。请先写定位层级，不写病名。
```

## 45-55 min — Feedback

学生作答后，教师侧读取当天私有文件进行讲评。讲评必须说明：定位层级、证据、排除理由、下一次复测题型。

## 55-60 min — State Update

更新：`state/score-history.md`、`state/topic-ledger.md`、`state/recall-deck.md`、`state/misconceptions.md`、`state/assessment-evidence-ledger.md`、`state/next-action.md`。
