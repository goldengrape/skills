# Day 5: 半球、小脑、前庭、基底节

## Today's Goal

完成 **半球、小脑、前庭、基底节** 的定位推理训练。作答时先定位解剖层级，再说明证据，不急着写疾病名称。

## Why This Matters for the Exam

考试题常把多个体征放在一起。如果只凭一个关键词作答，容易把脑干写成半球、把脊髓写成周围神经、把肌病写成神经根病。

## 0-5 min — Recall

不用笔记回答：

1. 昨天最容易混淆的一组定位是什么？
2. 今天主题中最重要的侧别或层级线索是什么？
3. 遇到不确定题目时，先找哪个反证？

## 5-10 min — Map

今天的位置：`course-map.md` → `失语、忽视、偏盲、共济失调、运动异常` → 病例作答 → 状态记录。

## 10-25 min — Core Explanation

本节只讲考试所需的最小定位规则。重点看：

- 失语支持优势半球语言网络，不能简单归为“说话不清”。
- 忽视常提示非优势顶叶/半球网络受累；偏盲提示视路后段，需结合其他半球线索。
- 小脑损害多为共济失调、辨距不良、意向震颤、眼震，肌力本身可相对保留。
- 基底节/锥体外系重点是运动过多或运动减少、肌张力异常，而不是典型 Babinski 阳性偏瘫。

## 25-35 min — Feynman Task

学生提示：

```text
用自己的话解释：失语、忽视、偏盲为什么是皮层/半球定位线索？再说明小脑共济失调和锥体束无力有什么不同。
```

## Diagram Cue

进入病例前，先打开 `assets/diagrams/index.md` 中对应图示，用 30 秒确认病灶层级和侧别关系。

## 35-50 min — Exam Practice

先独立作答，不读取教师侧答案。每题都按这个格式写：

```text
1. 定位结论：
2. 支持证据 A：
3. 支持证据 B：
4. 我排除的第一个错误定位：
5. 排除理由：
6. 还需补充的一个查体/病史：
```

### DAY5-CASE-A: 典型题

```text
右利手患者说话不流利但能理解简单命令，同时右侧下部面瘫和右上肢无力。请定位。
```
### DAY5-CASE-B: 反例题

```text
患者走路不稳，右手指鼻试验不准，肌力基本正常，无 Babinski 征。请说明为什么不应把它写成右侧锥体束病变。
```

## 50-56 min — Feedback

学生作答后，由课程运行者调用教师侧私有讲评材料进行反馈；学生侧文件不暴露答案路径。讲评必须说明：定位层级、证据、排除理由、常见误判、下一次复测题型。
