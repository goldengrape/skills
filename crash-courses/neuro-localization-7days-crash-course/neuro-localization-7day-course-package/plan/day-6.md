# Day 6: 周围定位

## Today's Goal

完成 **周围定位** 的定位推理训练。作答时先定位解剖层级，再说明证据，不急着写疾病名称。

## Why This Matters for the Exam

考试题常把多个体征放在一起。如果只凭一个关键词作答，容易把脑干写成半球、把脊髓写成周围神经、把肌病写成神经根病。

## 0-5 min — Recall

不用笔记回答：

1. 昨天最容易混淆的一组定位是什么？
2. 今天主题中最重要的侧别或层级线索是什么？
3. 遇到不确定题目时，先找哪个反证？

## 5-10 min — Map

今天的位置：`course-map.md` → `神经根、神经丛、单神经、多发神经、神经肌接头、肌肉` → 病例作答 → 状态记录。

## 10-25 min — Core Explanation

本节只讲考试所需的最小定位规则。重点看：

- 神经根病常有皮节分布疼痛/感觉异常和相应肌群、反射改变。
- 单神经病按某一周围神经支配区分布；丛病常跨多个根和多个周围神经。
- 多发周围神经病常是远端对称、手套袜套样、踝反射先减弱。
- 神经肌接头病常有波动和易疲劳，感觉正常；肌病常近端无力、感觉正常、早期反射相对保留。

## 25-35 min — Feynman Task

学生提示：

```text
用自己的话解释：根、丛、单神经、多发神经、神经肌接头、肌肉这几层怎样按分布、感觉、反射和疲劳性区分。
```

## Diagram Cue

进入病例前，先打开 `assets/diagrams/index.md` 中对应图示，用 30 秒确认病灶层级和侧别关系。

## 35-50 min — Exam Practice

先独立作答，不读取教师侧答案。每题都按这个格式写：

```text
1. 定位结论：
2. 支持证据 A：
3. 支持证据 B：
4. 我排除的第一个错误定位：
5. 排除理由：
6. 还需补充的一个查体/病史：
```

### DAY6-CASE-A: 典型题

```text
患者双足麻木逐渐上行，踝反射减弱，远端感觉下降，近端肌力尚可。请定位层级。
```
### DAY6-CASE-B: 反例题

```text
患者上楼和梳头困难，近端肌无力，感觉正常，腱反射早期保留。请定位到神经轴末端层级，并说明与周围神经病的区别。
```

## 50-56 min — Feedback

学生作答后，由课程运行者调用教师侧私有讲评材料进行反馈；学生侧文件不暴露答案路径。讲评必须说明：定位层级、证据、排除理由、常见误判、下一次复测题型。
