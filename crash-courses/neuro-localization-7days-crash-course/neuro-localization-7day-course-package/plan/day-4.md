# Day 4: 脑干与脑神经定位

## Today's Goal

完成 **脑干与脑神经定位** 的定位推理训练。作答时先定位解剖层级，再说明证据，不急着写疾病名称。

## Why This Matters for the Exam

考试题常把多个体征放在一起。如果只凭一个关键词作答，容易把脑干写成半球、把脊髓写成周围神经、把肌病写成神经根病。

## 0-5 min — Recall

不用笔记回答：

1. 昨天最容易混淆的一组定位是什么？
2. 今天主题中最重要的侧别或层级线索是什么？
3. 遇到不确定题目时，先找哪个反证？

## 5-10 min — Map

今天的位置：`course-map.md` → `同侧脑神经体征 + 对侧长束体征` → 病例作答 → 状态记录。

## 10-25 min — Core Explanation

本节只讲考试所需的最小定位规则。重点看：

- 脑干题的入口是交叉性体征：脑神经多同侧，长束体征常对侧。
- III 多提示中脑方向；VI、VII 多提示脑桥方向；IX/X、XII 多提示延髓方向。
- 眼球运动异常、面瘫类型、吞咽构音和长束体征要一起看，不能只看肢体侧别。
- 如果只有对侧偏瘫而无脑神经或皮层线索，不能强行定位脑干。

## 25-35 min — Feynman Task

学生提示：

```text
用自己的话解释：同侧脑神经体征加对侧肢体体征为什么提示脑干？请用一个小病例说明。
```

## Diagram Cue

进入病例前，先打开 `assets/diagrams/index.md` 中对应图示，用 30 秒确认病灶层级和侧别关系。

## 35-50 min — Exam Practice

先独立作答，不读取教师侧答案。每题都按这个格式写：

```text
1. 定位结论：
2. 支持证据 A：
3. 支持证据 B：
4. 我排除的第一个错误定位：
5. 排除理由：
6. 还需补充的一个查体/病史：
```

### DAY4-CASE-A: 典型题

```text
患者右眼外展受限，左侧肢体无力，左侧 Babinski 阳性。请定位并说明依据。
```
### DAY4-CASE-B: 迷惑题

```text
患者左侧肢体无力，左侧 Babinski 阳性，同时出现失语。没有眼球运动异常或周围性面瘫。请说明它为什么更像半球病变而不是脑干病变。
```

## 50-56 min — Feedback

学生作答后，由课程运行者调用教师侧私有讲评材料进行反馈；学生侧文件不暴露答案路径。讲评必须说明：定位层级、证据、排除理由、常见误判、下一次复测题型。
