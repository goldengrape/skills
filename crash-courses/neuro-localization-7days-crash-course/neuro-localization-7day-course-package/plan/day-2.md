# Day 2: 运动系统定位

## Today's Goal

完成 **运动系统定位** 的定位推理训练。作答时先定位解剖层级，再说明证据，不急着写疾病名称。

## Why This Matters for the Exam

考试题常把多个体征放在一起。如果只凭一个关键词作答，容易把脑干写成半球、把脊髓写成周围神经、把肌病写成神经根病。

## 0-5 min — Recall

不用笔记回答：

1. 昨天最容易混淆的一组定位是什么？
2. 今天主题中最重要的侧别或层级线索是什么？
3. 遇到不确定题目时，先找哪个反证？

## 5-10 min — Map

今天的位置：`course-map.md` → `UMN/LMN、偏瘫、截瘫、四肢瘫` → 病例作答 → 状态记录。

## 10-25 min — Core Explanation

本节只讲考试所需的最小定位规则。重点看：

- UMN 线索：痉挛性无力、腱反射活跃、Babinski 阳性、肌萎缩不明显。
- LMN 线索：弛缓性无力、腱反射减弱、明显肌萎缩或束颤。
- 偏瘫先考虑对侧锥体束，但必须再找皮层功能、脑神经交叉体征或脊髓线索。
- 截瘫或双下肢 UMN 体征合并感觉平面、括约肌异常时，优先考虑脊髓层级。

## 25-35 min — Feynman Task

学生提示：

```text
用自己的话解释：为什么肌张力、腱反射、病理征和肌萎缩能帮助区分 UMN 与 LMN？请用一个小病例说明。
```

## Diagram Cue

进入病例前，先打开 `assets/diagrams/index.md` 中对应图示，用 30 秒确认病灶层级和侧别关系。

## 35-50 min — Exam Practice

先独立作答，不读取教师侧答案。每题都按这个格式写：

```text
1. 定位结论：
2. 支持证据 A：
3. 支持证据 B：
4. 我排除的第一个错误定位：
5. 排除理由：
6. 还需补充的一个查体/病史：
```

### DAY2-CASE-A: 典型题

```text
患者双下肢无力，肌张力增高，膝反射活跃，T10 以下痛温觉下降。请定位并说明路径。
```
### DAY2-CASE-B: 反例题

```text
患者右手第一骨间肌萎缩，手指外展无力，右上肢腱反射减弱，无 Babinski 征。请说明它为什么不像单纯上运动神经元病变。
```

## 50-56 min — Feedback

学生作答后，由课程运行者调用教师侧私有讲评材料进行反馈；学生侧文件不暴露答案路径。讲评必须说明：定位层级、证据、排除理由、常见误判、下一次复测题型。
