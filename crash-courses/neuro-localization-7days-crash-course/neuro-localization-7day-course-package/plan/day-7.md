# Day 7: 混合模拟与最后冲刺

## Today’s Goal

完成 混合模拟与最后冲刺 的定位推理训练。作答时先定位解剖层级，再说明证据，不急着写疾病名称。

## Why This Matters for the Exam

考试题常把多个体征放在一起。如果只凭一个关键词作答，容易把脑干写成半球、把脊髓写成周围神经、把肌病写成神经根病。

## Time Policy

```yaml
total_minutes: 60
time_policy: exact_for_mock_exam
mode: full_mock_replaces_regular_micro-lesson
new_A_topics_limit: 0
feedback_timing: after_submission_or_next_review_block
```

Day 7 不再新增知识点。基础较弱学生应把 60 分钟优先用于完整模拟卷，而不是把 9 题压缩进 20 分钟。

## 0-5 min — Setup

不用笔记写下今天的答题格式：

```text
定位结论 → 支持证据 A → 支持证据 B → 排除的错误定位 → 排除理由 → 补充线索
```

## 5-55 min — Full Mock Exam

打开 `final-review/mock-exam.md`，完成 9 道混合模拟题。每题必须至少写：定位层级、2 条支持证据、1 条排除理由。

```yaml
recommended_split:
  section_a_quick_localization: 18_minutes
  section_b_discrimination: 14_minutes
  section_c_mixed_cases: 18_minutes
  final_check: 5_minutes
```

## 55-60 min — Submit and State Marking

先提交自己的答案，再读取教师侧讲评材料。若时间不足，先记录未答题号，不允许边看答案边补写。

更新：`state/score-history.md`、`state/topic-ledger.md`、`state/recall-deck.md`、`state/misconceptions.md`、`state/assessment-evidence-ledger.md`、`state/next-action.md`。

## Feedback Rule

Day 7 的教师反馈可以在提交后立即进行，也可以作为下一次 review block 单独完成。不要为了讲评压缩正式模拟作答时间。
