# Peripheral and Motor Unit Localization Module

## Purpose

本模块训练神经根、神经丛、单一周围神经、多发周围神经、神经肌接头和肌肉之间的定位区分。周围定位不能靠“哪个名词熟”来选，必须看分布、感觉、反射和波动性。

## Core Rule: 分布优先于名称

| Pattern | Likely level | What would weaken this answer |
|---|---|---|
| 皮节痛麻 + 肌节无力 + 对应反射改变 | nerve root | 完全符合单一周围神经 territory |
| 跨多个根和多个周围神经，片状分布 | plexus | 远端对称手套袜套 |
| 符合单一神经走行 | peripheral nerve | 根性疼痛和肌节模式更强 |
| 远端对称、长度依赖、反射减弱 | polyneuropathy | 清楚躯干感觉平面或 Babinski |
| 波动疲劳、眼咽受累、感觉正常 | NMJ | 固定感觉缺损或明显萎缩束颤 |
| 近端无力、感觉正常、反射早期保留 | muscle | 远端感觉异常、反射明显减弱 |

## Worked Example 1: 根病 vs 单神经病

题干：患者颈部疼痛向拇指放射，肱二头肌反射减弱，肘屈无力，感觉异常不完全符合一个单一周围神经。

作答链条：

```text
定位结论：神经根病方向。
支持证据：根性疼痛、肌节无力、对应反射改变。
排除理由：单一周围神经病应更符合某一神经的固定感觉运动分布；本题跨越单神经边界。
```

## Worked Example 2: 肌病 vs NMJ

题干：患者近端无力，上楼和梳头困难，感觉正常，腱反射早期保留，无明显眼睑下垂或复视波动。

定位思路：近端为主、感觉正常、反射早期保留，支持肌肉层级。若出现晨轻暮重、疲劳后加重、眼睑下垂和复视，应转向神经肌接头。若有远端感觉异常和反射减弱，则转向周围神经。

## Failure Cases

1. **有感觉缺损仍写 NMJ/肌病。** NMJ 和肌病通常感觉正常，除非另有合并问题。
2. **把所有远端麻木写成脊髓。** 远端对称、长度依赖、踝反射下降更支持多发周围神经病。
3. **把根、丛、神经混用。** 根按皮节/肌节，神经按命名神经 territory，丛常跨多个根和周围神经。

## Check Yourself

周围定位题必须回答：

```text
感觉分布是什么形状？反射是否对应？是否有波动疲劳？近端还是远端为主？
```

## Boundary Drill

周围定位题的答题顺序建议固定为：分布、感觉、反射、波动性。分布决定根/丛/神经的大方向；感觉是否正常帮助排除 NMJ 和肌病；反射减弱常支持周围或 LMN；波动疲劳和眼咽受累提示 NMJ。若题干只给“疼痛”或“麻木”，不能直接下结论，必须追问分布。
