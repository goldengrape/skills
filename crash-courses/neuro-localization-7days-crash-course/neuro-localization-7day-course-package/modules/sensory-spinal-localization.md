# Sensory and Spinal Localization Module

## Purpose

本模块训练从感觉类型、感觉平面、感觉分离、双侧长束体征和括约肌线索定位脊髓及感觉通路。脊髓题最容易被误写成“周围神经病”或“腰椎间盘突出”，所以必须先抓层级。

## Core Rule: 感觉平面优先级很高

如果题干出现“胸部以下”“脐以下”“某一水平以下”感觉改变，并伴随双下肢 UMN 体征或大小便异常，应优先考虑脊髓。手套袜套样远端对称感觉异常不是感觉平面。

## Sensory Pathway Clues

| 线索 | 定位意义 |
|---|---|
| 痛温觉异常 | 脊髓丘脑束或相关通路 |
| 振动觉、位置觉异常 | 后索或大纤维感觉通路 |
| 感觉平面 | 脊髓节段性定位强线索 |
| 鞍区感觉异常 | 圆锥/马尾相关线索 |
| 根性疼痛 | 神经根或马尾更常见 |

## Worked Example 1: Brown-Séquard 型题

题干：右下肢无力、右侧 Babinski 阳性；右侧位置觉下降；左侧痛温觉下降，感觉异常从胸部某水平以下开始。

作答链条：

```text
定位结论：右侧脊髓半侧损害方向。
支持证据：右侧 UMN + 右侧后索深感觉受损，伴对侧痛温觉受损，形成感觉分离和侧别交叉。
排除理由：单一周围神经或神经根不能解释双侧不同感觉通路的组合；多发周围神经病也不能形成清楚感觉平面。
```

## Worked Example 2: 圆锥与马尾

题干：鞍区麻木、尿潴留，双下肢疼痛明显，一侧更重，踝反射下降。

定位思路：鞍区感觉和大小便问题提示圆锥/马尾区域；明显根性疼痛、不对称、LMN 体征更偏马尾。若大小便很早出现、较对称、根痛不突出，更偏圆锥。

## Failure Cases

1. **把“胸部以下感觉下降”写成多发周围神经病。** 周围神经病多为远端对称、长度依赖，不形成躯干水平。
2. **只写病因，不写综合征。** 如“脊髓炎”“压迫”都不是定位本身。先写脊髓层级和受累通路。
3. **忽略感觉类型。** 痛温和深感觉的分离，常比“麻木”这个词本身更有定位价值。

## Check Yourself

脊髓题至少写出三项：

```text
平面在哪里？哪些传导束受累？是否有括约肌或双侧长束体征？
```

## Boundary Drill

遇到“麻木”二字，不要立即选择脊髓或周围神经。先把分布写出来：如果是从躯干某一水平以下改变，且伴双侧 UMN 或括约肌线索，脊髓优先；如果是双足开始、远端对称、反射减弱，周围多发神经病优先。这个步骤可以减少把感觉平面和长度依赖模式混淆的错误。
