# Motor Localization Module

## Purpose

本模块训练从肌力、肌张力、反射、病理反射、萎缩、束颤和分布模式判断运动系统病灶层级。它只回答“病灶大概在哪里”，不直接替代病因诊断。

## Core Rule: 先判断模式，再判断部位

运动定位不要从疾病名开始。先问三个问题：

1. 这是真正的无力，还是疼痛、共济失调、意识障碍或不配合造成的“看起来无力”？
2. 体征更像 UMN、LMN，还是神经肌接头/肌肉？
3. 分布是单肢、偏身、截瘫、四肢，还是远端对称/近端为主？

## UMN 与 LMN 的最小判别表

| 项目 | UMN 更支持 | LMN 更支持 |
|---|---|---|
| 肌张力 | 痉挛性增高 | 降低或松弛 |
| 腱反射 | 活跃或亢进 | 减弱或消失 |
| 病理征 | Babinski 等阳性 | 通常阴性 |
| 萎缩 | 轻，常为废用性 | 明显，可伴束颤 |
| 分布 | 偏身、截瘫、四肢瘫等长束模式 | 根、神经、前角细胞或周围神经模式 |

## Worked Example 1: 偏瘫题不能一步跳到半球

题干：右侧肢体无力，右侧 Babinski 阳性，肌张力增高。没有语言、忽视、偏盲、脑神经、感觉平面信息。

作答链条：

```text
定位结论：左侧锥体束/UMN 通路病变，位于锥体交叉以上；暂不能只写左侧大脑半球。
支持证据：右侧无力 + 右侧 Babinski + 肌张力增高。
排除理由：没有萎缩、束颤、反射减弱，不支持主要 LMN；缺少皮层功能线索，半球定位还不稳。
补充线索：查失语、忽视、偏盲、眼球运动、面瘫类型、感觉平面。
```

失败写法：

```text
答案：左侧脑梗。
```

问题在于它把病因和定位混在一起，也没有说明为什么不是脑干或脊髓。

## Worked Example 2: 四肢无力先分层

题干：急性四肢无力，腱反射减弱，无感觉平面，无 Babinski，感觉轻度远端异常。

定位思路：反射减弱和无病理征使 UMN 脊髓病变不优先；若为远端感觉异常和反射减弱，要考虑多发周围神经或多发神经根。若感觉正常、波动疲劳、眼睑下垂，则转向神经肌接头。若近端为主、感觉正常、反射早期保留，则转向肌肉。

## Failure Cases

1. **把“无力”当成定位结论。** 无力只是症状，必须继续判断 UMN/LMN/肌肉/NMJ。
2. **把所有偏瘫都写成半球。** 偏瘫可来自半球、内囊、脑干、高颈髓。脑神经交叉体征和皮层功能线索是关键。
3. **忽略反射和病理征。** 同样是无力，反射亢进和反射消失指向完全不同的层级。
