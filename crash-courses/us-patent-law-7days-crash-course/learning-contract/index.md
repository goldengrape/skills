## Learning stages

| Level | Meaning | Minimum evidence |
|---|---|---|
| L1 | heard of | no longer unfamiliar |
| L2 | can follow | follows an explanation |
| L3 | can recognize | identifies concept in context |
| L4 | can retrieve | recalls definition or rule without notes |
| L5 | standard use | applies the rule to same-type tasks |
| L6 | misuse discrimination | detects common confusions and flawed answers |
| L7 | transfer | uses concept in a new or cross-day context |
| L8 | fluency | low-hint, mixed, or timed use |
| L9 | critique / teach / create | teaches, critiques, designs examples, or creates |

## Assistance modes

- guided → assisted_score
- semi_guided → semi_assisted_score
- blind → blind_score

## A-topic requirement

A-priority concepts target L6 by default. That means the learner must not only repeat the rule, but also detect misuse, such as treating novelty as eligibility or treating PHOSITA as the inventor.

## L7 option

If learner wants deeper skill, add transfer checks: new fact pattern, mixed §101/102/103/112 route selection, or cross-day infringement analysis.

## Source and evidence rule

Feedback should be anchored to learner output, source hierarchy, and exam task type. Do not state stability beyond the evidence level shown in `state/concept-mastery-state.md`.
