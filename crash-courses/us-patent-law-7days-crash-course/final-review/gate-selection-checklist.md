# Gate Selection Checklist

Use this before any issue-spotting answer. The goal is to stop using one doctrine to answer another doctrine.

## 1. First identify what the question asks

| If the facts emphasize... | Usually check... | Do not answer with... |
|---|---|---|
| type of claimed subject matter, abstract idea, natural law, generic computer | §101 eligibility | “No prior art” |
| one reference discloses every element | §102 anticipation / novelty | “It feels obvious” |
| two or more references, PHOSITA, reason to combine | §103 obviousness | “No single reference, so safe” |
| specification examples, claim breadth, possession, undue experimentation | §112 written description / enablement | “It is new” |
| unclear claim terms | §112 definiteness or claim construction | “Product is similar” |
| accused product and claim terms | infringement | patentability analysis alone |
| injunction, damages, enhanced damages | remedies | automatic injunction / automatic treble damages |
| IPR/PGR/PTAB | authorization-post-grant procedure | district-court infringement only |

## 2. Four-sentence opening template

```text
The first issue is [gate], because the facts emphasize [trigger fact]. That gate asks [legal question]. I will not use [adjacent gate] to answer it because [reason]. The missing facts that would matter are [facts].
```

## 3. Red flags

Rewrite your answer if it starts like any of these:

- “It is patentable because it is valuable.”
- “It is eligible because no prior art discloses it.”
- “It is nonobvious because no single reference has every element.”
- “One example supports the whole claim.”
- “The product is similar, so it infringes.”
- “The patent owner won, so injunction and treble damages are automatic.”

## 4. Final exam use

Before Part C, spend 3 minutes listing gates:

```text
§101: facts that trigger it = ...
§102: facts that trigger it = ...
§103: facts that trigger it = ...
§112: facts that trigger it = ...
Claim construction / infringement: facts that trigger it = ...
```
