# Prior Art Search Lab

## 目的

本练习不是训练执业级检索，而是让学习者理解 §102 和 §103 为什么离不开 prior art。

## 工具入口

- USPTO Patent Public Search
- USPTO Patent Search page
- Google Patents or other public search tools may be used only as secondary aids

## Mini-lab A — Sleep app

A mobile app collects sleep duration and heart-rate data, calculates a risk score using a known statistical formula, and displays a health suggestion.

Tasks:

1. List the claim elements in plain English.
2. Search for one reference that discloses collecting sleep data.
3. Search for one reference that discloses a risk score or health suggestion.
4. Decide whether your facts look more like a §102 problem or a §103 problem.
5. Record one uncertainty you would not overclaim.

## Mini-lab B — Predictive maintenance

A software tool predicts industrial equipment failure using a known statistical method in a new maintenance context.

Tasks:

1. Separate the data collection step, algorithm step, and alert step.
2. Find a reference for the statistical method.
3. Find a reference for maintenance alerts.
4. Explain whether combining them is predictable or not.
5. State why this is not enough by itself to decide §101 or §112.

## Teacher use

Teacher should review the search process, not only the final yes/no conclusion. A weak but honest record with uncertainty is better evidence than a confident unsupported answer.
