# Day 2 Worked Example: Alice/Mayo 不等于 novelty test

## 使用场景

用于 Day 2 正课之后、quiz 之前。目标不是预测真实案件结果，而是训练学生把 §101 eligibility 和 §102 / §103 分开。

## Fact pattern A

Claim 1 recites: “A method performed by a generic computer, comprising receiving a user’s daily spending data, applying a known budgeting formula, and displaying whether the user is overspending.”

The specification says the method can run on an ordinary phone or server. It does not describe a new database structure, new sensor, new network protocol, or new computer performance improvement.

## Step-by-step analysis

### Step 0 — 先确认本题只问 §101

Do not start with “no prior art” or “the formula is old.” Those facts may matter later, but §101 first asks whether the claimed subject matter is eligible.

### Step 1 — statutory category

The claim is framed as a **method/process**, so it likely fits one statutory category. That does not end the analysis.

### Step 2A — possible judicial exception

The claim may be directed to an **abstract idea**, such as organizing human financial activity, mental calculation, or mathematical formula use.

### Step 2A practical-application check

Ask whether the claim integrates the abstract idea into a practical application. Facts cutting against eligibility include:

- ordinary receiving of data;
- ordinary calculation;
- ordinary display of a result;
- generic computer implementation.

Facts that would help eligibility, if present, could include:

- a specific improvement to computer functionality;
- a new technical way to process data;
- control of a physical device in a non-generic technical process;
- a claim limitation that changes how the computer or network operates.

### Step 2B — additional elements / significantly more

If the claim is directed to a judicial exception, ask whether additional elements add significantly more. Merely saying “do it on a computer” or “show the answer on a screen” is usually weak.

## Short model answer

This claim likely fits the statutory category of process, but it may be directed to an abstract idea: applying a budgeting formula to financial data and displaying a result. The stated computer elements appear generic. On these facts, the claim has §101 risk unless additional claim limitations show a specific technical improvement or a practical application beyond ordinary data collection, calculation, and display. Whether the method is new or obvious should be handled separately under §102 and §103.

## Common wrong answer and repair

Wrong answer:

> It is patent eligible because no prior art has the exact same budgeting app.

Repair:

> That uses §102 reasoning to answer §101. For eligibility, first ask whether the claim is a process, then whether it is directed to an abstract idea, and whether the additional elements add a practical application or significantly more.

## Transfer mini-drill

Now analyze this different claim in four sentences:

Claim 2 recites a method for controlling an industrial oven, using sensor readings and a specific new control sequence to reduce temperature oscillation in the oven hardware.

Use this skeleton:

1. Statutory category: ...
2. Possible exception: ...
3. Practical application / technical improvement facts: ...
4. What should be reserved for §102 / §103: ...
