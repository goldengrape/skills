# Day 4: §103 nonobviousness, PHOSITA, Graham, and KSR

## Today’s Goal

能用 prior art + PHOSITA 解释为什么 obvious 或 nonobvious，而不是凭感觉。

## Why This Matters for the Exam

本日内容对应课程 A/B 类主题，重点不是背术语，而是能在短事实中识别问题、拆分规则、避免混淆。

## Time Policy

```yaml
total_minutes: 60
time_policy: soft
new_A_topics_limit: 3
teacher_private_material: hidden_until_learner_answer
```

## 0-5 min — Recall

1. 今天涉及哪些关键词：PHOSITA、Graham factors、KSR flexible approach、motivation to combine、secondary considerations、hindsight？
2. 昨天内容中哪一个概念会影响今天判断？
3. 你最容易把今天主题和哪条规则混淆？

## 5-10 min — Map

先画一条小路径：

```text
facts → claim / source → legal gate → rule → application → uncertainty
```

今天只分析指定 gate；不要把所有专利法问题一次性混在一起。

## 10-25 min — Core Explanation

- §103 问：即使没有单一 reference 完整公开，claim 是否对 PHOSITA 显而易见。
- Graham 框架：prior art 范围和内容、claim 与 prior art 差异、PHOSITA 水平、secondary considerations。
- KSR 反对僵硬 TSM，但不等于“任何组合都 obvious”。
- 分析组合时，要说明为什么 PHOSITA 会组合、是否 predictable、是否有 teaching away。
- 防止 hindsight：不能因为看到发明结果后倒推“这很简单”。

## 25-35 min — Case / Source Link

阅读 `case-cards/core-case-cards.md` 中与今天主题相关的 1–3 张卡。只回答四件事：

1. 这个案子解决了什么问题？
2. 它限制了哪种直觉答案？
3. 它最容易被误读成什么？
4. 它如何改变你对今天事实题的分析？

## Darwin R2 Patch — PHOSITA / Motivation Fact Bank

在 35–48 min 的 Exam Practice 前，先打开 `practice/phosita-motivation-fact-bank.md`。

要求学生从 fact bank 中至少选择：

- 一个 PHOSITA profile fact；
- 一个支持 obvious 的事实类型；
- 一个反对 obvious 的事实类型；
- 一个 hindsight warning。

禁止只写“KSR says flexible”或“组合很简单”。每个结论必须接一个具体事实。

## 35-48 min — Exam Practice

Reference A 公开智能水杯传感器；Reference B 公开手机提醒算法。Claim 把二者组合成饮水提醒系统。
1. 用 Graham 列出分析框架。
2. 给出一个支持 obvious 的理由。
3. 给出一个反对 obvious 的理由。
4. 指出一个 hindsight 风险。
5. 哪些事实可作为 secondary considerations？
