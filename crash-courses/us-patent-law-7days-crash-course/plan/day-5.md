# Day 5: §112 written description, enablement, definiteness, and claim scope

## Today’s Goal

能把“发明人是否占有”“能否实施”“claim 是否清楚”分开。

## Why This Matters for the Exam

本日内容对应课程 A/B 类主题，重点不是背术语，而是能在短事实中识别问题、拆分规则、避免混淆。

## 5-10 min — Map

先画一条小路径：

```text
facts → claim / source → legal gate → rule → application → uncertainty
```

今天只分析指定 gate；不要把所有专利法问题一次性混在一起。

## 10-25 min — Core Explanation

- Written description 问申请日材料是否显示 inventor possessed claimed invention。
- Enablement 问本领域技术人员能否无需 undue experimentation 实施 claim 全部范围。
- Definiteness 问 claim 是否以 reasonable certainty 告知范围。
- Claim 越宽，specification 支持压力越大；几个 example 未必支持整个 genus。
- §112 与 claim drafting 绑定：宽 claim 可能商业上诱人，但法律上更容易不稳。

## Darwin R2 Patch — Broad Claim Drill

在 35–48 min 的 Exam Practice 后，完成 `practice/section-112-broad-claim-drills.md` 中 Drill A。若时间允许，补做 Drill B。

最低完成要求：

1. 先判断 claim scope 是否宽。
2. Written description 必须写 possession。
3. Enablement 必须写 full scope / undue experimentation。
4. 至少列出两个让 claim 更稳或更危险的事实。

如果学生把 written description 和 enablement 写成同一句话，记录为高优先误区，并在下一次复习中重测。

## 35-48 min — Exam Practice

3. 为什么 claim scope 会影响答案？
4. 哪些事实会让 claim 更稳？
5. 哪些事实会让 claim 更危险？
