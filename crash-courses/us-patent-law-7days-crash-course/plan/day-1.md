# Day 1: Patent system map, patent types, application posture, and claims as boundary

## Today’s Goal

把“专利权是什么”与“申请处于什么姿态”分开。

## Why This Matters for the Exam

本日内容对应课程 A/B 类主题，重点不是背术语，而是能在短事实中识别问题、拆分规则、避免混淆。

## 5-10 min — Map

先画一条小路径：

```text
facts → claim / source → legal gate → rule → application → uncertainty
```

今天只分析指定 gate；不要把所有专利法问题一次性混在一起。

## 10-25 min — Core Explanation

- Patent bargain：公开技术信息，换取有限期间的排他权。
- Right to exclude：专利权通常不是“我可以实施”，而是“我可以排除他人制造、使用、销售等”。
- Utility patent 保护功能性发明；design patent 保护外观设计；plant patent 是特殊类别。
- Provisional application 可帮助建立较早申请日，但不会自动变成授权专利。
- Claim 是法律边界；specification 支持 claim，但侵权和有效性分析通常从 claim 开始。
