# Day 3: §102 novelty, prior art, and anticipation

## Today’s Goal

能判断 §102 是否是“单一现有技术公开每个 claim element”的问题。

## Why This Matters for the Exam

本日内容对应课程 A/B 类主题，重点不是背术语，而是能在短事实中识别问题、拆分规则、避免混淆。

## 5-10 min — Map

先画一条小路径：

```text
facts → claim / source → legal gate → rule → application → uncertainty
```

今天只分析指定 gate；不要把所有专利法问题一次性混在一起。

## 10-25 min — Core Explanation

- Novelty 问的是 claim 是否已经被 prior art 公开。
- Anticipation 通常要求一个 prior art reference 公开 claim 的每个要素。
- Prior art 不限于专利，也可能是 printed publication、public use、sale 等。
- On-sale bar 要注意 Pfaff / Helsinn 相关风险，不要只看销售是否公开。
- AIA 规则中有 grace period，但 7 天速通只训练识别问题，不做复杂期限计算。

## 35-48 min — Exam Practice

1. 哪个 reference 最可能触发 anticipation 分析？
2. 如果只有 Reference 1 和 2，为什么不能直接说 §102 anticipation？
3. 哪些事实会变成 §103 问题？
4. 写下一个 prior art search 记录项。
