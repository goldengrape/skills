# Diagram Source Rules

- If a diagram is generated locally, record the file path, purpose, and source basis.
- If a diagram is taken from an external source, use authoritative or open-source sources and record the link.
- Do not use unattributed diagrams from random websites.
- For USPTO process figures, prefer USPTO pages or recreate a simplified diagram from textual guidance.
