# Visibility Rules

## Before Learner Answers

Allowed:

- question
- length limit
- time limit
- output format
- note policy

Forbidden:

- expected answer elements
- rubric
- answer key
- standard answer
- internal judgment

## After Learner Answers

Allowed:

- missing points
- scoring explanation
- corrected wording
- compact model response
- recall card
- misconception repair

## Teacher-private files

- `teacher/teacher-notebook.md`
- `teacher/rubrics/*.md`
- `teacher/answer-keys/*.md`

Guided practice may use scaffolds, but scores must then be recorded as `assisted_score` or `semi_assisted_score`.
