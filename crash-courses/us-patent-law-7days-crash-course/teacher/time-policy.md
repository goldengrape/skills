# Time Policy

```yaml
default: soft
strict_available: true
daily_minutes: 60
```

## soft mode

The 60-minute plan is a design target. Learner-led questions may extend or reshape a segment when they improve understanding of A topics.

## strict mode

Use strict timing only when learner asks for it. Under strict mode, keep explanations shorter, reduce B topics, and move interest branches to the ledger.
