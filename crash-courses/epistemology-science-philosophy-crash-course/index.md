# 认识论与科学哲学速通课 OKF

这是一个 7 天左右、每天约 60 分钟的 stateful crash course learning OKF。课程按正统哲学课程组织：认识论核心问题 → 休谟与康德 → 当代知识理论 → 科学哲学中的归纳、证伪、整体论与范式问题。

## 入口

- 课程使命：`mission.md`
- 课程地图：`course-map.md`
- 优先级：`priority-map.md`
- 每日计划：`plan/seven-day-plan.md`
- 当前状态：`state/current-state.md`
- 下一步：`state/next-action.md`
- Day 1 入口：`plan/day-1.md`

## 使用规则

开始每次学习前，先读 `state/`、当天 `plan/day-N.md`、当天 `quizzes/day-N-quiz.md`，再开始教学。作答前不展示教师侧 rubrics 或 answer keys。学习后更新 `sessions/`、`learning-records/`、`state/score-history.md`、`state/recall-deck.md` 和 `state/misconceptions.md`。
