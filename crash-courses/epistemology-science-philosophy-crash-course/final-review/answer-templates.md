# Answer Templates

## 名词解释

1. 先给一句定义。
2. 写出它解决的问题。
3. 给一个例子或反例。
4. 写一个容易混淆的边界。

## 判断并修正

1. 判断原说法的问题。
2. 指出误解来自哪里。
3. 改写成更准确的版本。
4. 必要时补一句适用范围。

## 概念比较

1. 共同问题。
2. A 的核心回答。
3. B 的核心回答。
4. 关键差异。
5. 一个例子。

## 迁移题

1. 先说原概念。
2. 再说新案例中相似的结构。
3. 然后说不能直接等同的地方。
4. 最后给谨慎判断。
