# Visual Teaching Policy

Prefer Python / matplotlib for generated diagrams when a spatial structure, comparison matrix or process flow benefits understanding. Use authoritative external diagrams only when a generated image would be misleading or too slow. ASCII diagrams are limited to tiny temporary sketches and must not be used for complex structures.

For this philosophy course, diagrams are optional. A concept map may be generated for Day 7 if helpful.
