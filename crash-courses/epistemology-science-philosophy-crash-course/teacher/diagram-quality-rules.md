# Diagram Quality Rules

- Check title, labels, axis or structural labels when relevant.
- Avoid decorative diagrams that do not help concept distinction.
- If using a timeline or concept map, verify all arrows represent a real problem relation.
- Record every generated or sourced image in `assets/diagrams/index.md`.
