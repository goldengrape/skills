# Day 3 Rubric

## Score type

Default quiz mode is blind_score unless the learner received hints. If hints are given, use semi_assisted_score or assisted_score.

## Evaluation focus

四重区分、先天综合、感性形式、范畴、现象/物自体边界。

## Bands

- 90-100%: concept distinction is clear, wording is careful, and at least one misconception is avoided.
- 75-89%: core idea is present, with some missing precision.
- 60-74%: partial understanding; schedule repair.
- below 60%: stop dependent progression and reteach core concept.

## L6-L7 evidence

L6 requires flawed-statement repair. L7 requires a new-case transfer with explicit boundary.
