# Teaching Protocol

## Daily run

1. Read state files and relevant plan.
2. Present recall questions without pre-answer hints.
3. Teach core concepts using problem-first explanation.
4. Ask Feynman task.
5. Run quiz or practice.
6. After learner answers, provide score, hit/miss analysis, misconception repair and minimal reanswer task.
7. Update state, recall deck, misconceptions, score history, concept mastery state and teacher notebook.

## Feedback style

- 给事实和理由，再给修正表达。
- 先修 A 类误解，再处理 B/C 追问。
- 不把 AI 案例带入主线，除非已到 Day 7 或主线已完成。
