# Engagement Intervention Rules

- Preserve interest, but do not let C branches replace A concepts.
- If an interest question helps the current A concept, answer briefly and tie it back.
- If it would derail the day, record it in `state/interest-ledger.md` and schedule it for Day 7.
- If fatigue appears in observable answers, reduce examples and keep one repair question.
