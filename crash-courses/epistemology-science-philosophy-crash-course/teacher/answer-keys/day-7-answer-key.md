# Day 7 Answer Key

Teacher-private. Do not show before learner answers.

## 题 1｜综合比较

参考要点：

- 休谟：经验给出恒常联结和习惯期待，但不能理性证明因果必然联系或归纳原则。
- 康德：改变问题问法，说明经验对象之所以可能，需要主体的先天形式和范畴；但这不是主观随意造世界。
- 波普尔：科学理论不能靠归纳最终证明，只能通过可证伪性和严厉检验区分科学态度。
- 奎因：经验检验不是孤立命题接受检验，而是理论网络整体面对经验压力。
- 库恩：科学发展不只是命题逐条积累，也受范式、常规科学、异常积累和科学革命影响。

## 题 2｜误解修正

评分重点：先改写，再解释错误来源。鼓励使用“不是……而是……”句式。

- 休谟不是否定人类形成因果信念，而是质疑因果必然联系能否由理性或经验严格证明。
- 康德不是说世界由人脑任意创造，而是说经验对象的呈现受到认识形式和范畴条件制约。
- 波普尔不是说理论一遇到反例就毫无价值，而是强调理论必须冒被经验检验推翻的风险；科学实践还要处理辅助假设和测量条件。
- 库恩不是说科学只是主观共识，而是强调科学共同体在范式中进行常规研究；范式仍受问题解决能力和世界阻力约束。
- AI benchmark 不是波普尔意义上的完整证伪，只能在有限任务环境中暴露失败模式。

## 题 3｜AI benchmark 与证伪

高分答案应包含：

1. 判断：不能直接等同。
2. 相似点：benchmark 失败可以暴露模型能力边界，像检验一样提供反例压力。
3. 差异点：benchmark 是有限题集或任务环境；波普尔讨论的是理论结构是否具有可证伪性、是否接受严厉检验。
4. 边界：一个模型失败不等于一个科学理论被证伪；还要看任务设计、数据泄漏、评价指标、模型版本和辅助条件。

## 题 4｜训练数据与归纳

高分答案应包含：

1. 可以作有限类比：从大量样本中学习规律，类似从经验中形成期待。
2. 不能解决休谟问题：过去数据中出现的模式不能理性保证未来仍成立。
3. 不能把 token 或训练样本直接等同于休谟的印象；休谟讨论的是心灵经验内容，AI 是工程系统。
4. 能指出可验证奖励、形式化检查或 benchmark 只能提高检验强度，不能把归纳变成绝对证明。

## 题 5｜自我修正与康德

高分答案应包含：

1. 谨慎判断：不能说模型实现了康德的先天综合判断或统觉。
2. 可类比处：模型的自我检查、自我修正可能在功能上表现为对推理过程的再组织。
3. 不可等同处：康德讨论的是经验对象、判断客观有效性和主体统一性的先验条件，不是工程上的后验推理步骤。
4. 禁止过强说法：不要说 AI 具有康德意义上的主体性、意识、范畴或统觉。

## 题 6｜小论文

高分答案应形成清楚路线：

知识问题 → 怀疑论 → 休谟归纳问题 → 康德回应 → Gettier 与证成理论 → 波普尔证伪 → 奎因整体论 → 库恩范式 → 误解修正或迁移。

## 反馈动作

- 若 AI 题把“类似”写成“等同”，即使哲学名词使用正确，也必须安排 repair。
- 若主线题弱而 AI 题强，不允许用 AI 兴趣替代 A 类核心补课。
- 若学习者能清楚写出边界句，可记入 L7 transfer evidence。
