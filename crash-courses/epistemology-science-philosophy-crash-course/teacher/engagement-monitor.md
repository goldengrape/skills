# Engagement Monitor

Use observable signals only: response length, accuracy, self-correction, confusion markers, fatigue markers, and interest-led questions. Do not infer hidden mental states.

## Signals

| Signal | Possible response |
|---|---|
| Repeated same misconception | Stop and run repair task. |
| Strong self-correction | Increase transfer difficulty slightly. |
| Long interest branch | Record interest and protect the main line. |
| Short or tired answers | Compress B/C content and preserve A content. |
