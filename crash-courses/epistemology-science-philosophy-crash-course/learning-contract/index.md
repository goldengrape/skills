## L1-L9

| Level | Meaning | Minimum evidence |
|---|---|---|
| L1 | heard of | no longer unfamiliar |
| L2 | can follow | follows an explanation |
| L3 | can recognize | identifies concept in context |
| L4 | can retrieve | recalls definition or distinction without notes |
| L5 | standard use | solves same-type tasks |
| L6 | misuse discrimination | detects common confusions and flawed answers |
| L7 | transfer | uses concept in new or cross-domain cases |
| L8 | fluency | low-hint, mixed, or timed use |
| L9 | critique / teach / create | teaches, critiques, designs examples, or creates |

## Assistance modes

- guided：教师给较多提示。
- semi_guided：教师给题型和少量方向。
- blind：只给题目，不给概念提示。
- barehand：无笔记、无提示、跨日混合。

## Productive friction

学习中保留 independent recall。遇到困难时，先让学习者尝试，再给最小提示。不要把所有概念先展开成可抄答案。

## Low-value features not used

本课程不使用 badge、streak、leaderboard、排名或连续打卡作为学习目标。进展只根据回答证据、误解修正和迁移表现记录。

## 2-3 checkpoint rule

每 2-3 天安排一次 barehand 检查，确认学习者不是只会跟着解释走，而能在混合题中独立取用概念。
