# Priority Map

## A 类：核心内容，必须掌握

| 主题 | 类别 | 目标层级 | 可观察表现 |
|---|---|---|---|
| 什么是知识 | A | L6-L7 | 能区分知识、信念、真、证成；能判断 JTB 为什么不够。 |
| 怀疑论 | A | L6 | 能解释外部世界怀疑为何难以彻底排除，又为何不必导致日常知识全盘废弃。 |
| 休谟的因果与归纳问题 | A | L7 | 能说明经验只给出恒常联结，不给出必然联系；能迁移到科学预测。 |
| 康德的先天综合判断 | A | L7 | 能说明康德如何改变问题问法：不是知识如何贴合对象，而是对象如何作为经验对象被认识。 |
| 现象与物自体 | A | L6 | 能避免把康德误读为主观造世界。 |
| Gettier 问题 | A | L6-L7 | 能构造或识别被证成真信念但不是知识的案例。 |
| 基础主义 / 融贯论 / 可靠主义 | A | L6 | 能比较证成结构、系统一致性和形成过程可靠性的差异。 |
| 波普尔证伪主义 | A | L7 | 能说明科学理论不能被归纳证明，科学性来自可接受严厉检验的结构。 |
| 奎因整体论 | A | L7 | 能说明经验检验通常面向理论网络，不是孤立命题。 |
| 库恩范式理论 | A | L7 | 能区分范式、常规科学、异常、科学革命和不可通约性。 |

## 压缩规则

1. 如果当天时间不足，先保证 A 类概念能做名词解释、误解修正和小案例迁移。
2. B 类只讲到能支撑 A 类理解，不追求人物史完整性。
3. C 类只在每日最后 5 分钟或 Day 7 使用，不反客为主。
4. 任何 AI 案例都必须先回到对应哲学概念，再说明相似点和差异点。
