# 宏观经济学术语表

| Term | 及格线定义 |
|---|---|
| GDP | 一定时期内，一国境内生产的最终产品和服务的市场价值。 |
| Nominal GDP | 用当年价格计算的 GDP，既受产量影响，也受价格影响。 |
| Real GDP | 用基期价格计算的 GDP，更适合比较真实产出变化。 |
| GDP deflator | 名义 GDP / 实际 GDP × 100，用于衡量整体产出价格水平。 |
| CPI | 消费者价格指数，用固定消费篮子衡量消费者面对的价格水平。 |
| Inflation rate | 价格水平从一期到下一期的百分比变化。 |
| Unemployment rate | 失业人数占劳动力的比例。 |
| Labor force | 就业者与正在找工作的失业者之和。 |
| Aggregate demand, AD | 经济中在不同价格水平下对总产出的需求。 |
| SRAS | 短期总供给，反映短期价格和工资调整不完全时的产出供给。 |
| LRAS | 长期总供给，代表潜在产出，主要由资源和生产率决定。 |
| Output gap | 实际产出与潜在产出的差距。 |
| Fiscal policy | 政府通过支出和税收影响总需求和经济活动。 |
| Multiplier | 初始支出变化引发更大总产出变化的机制。 |
| Crowding out | 政府借款可能推高利率并挤出私人投资。 |
| Monetary policy | 中央银行通过货币供给和利率影响经济。 |
| Central bank | 实施货币政策、管理金融体系流动性的机构。 |
| Open market operations | 央行买卖政府债券以影响银行准备金和货币供给。 |
| Business cycle | 经济活动围绕长期趋势的扩张和收缩。 |
| Phillips curve | 短期内通胀和失业之间可能存在权衡关系。 |
| Exchange rate | 一种货币与另一种货币的兑换价格。 |
| Net exports, NX | 出口减进口，是支出法 GDP 的组成部分。 |

## 背诵方式

每个术语按三步记：一句定义、一个例子、一个易错点。考试时不要只写中文翻译，要写出它在模型或政策链条中的作用。
