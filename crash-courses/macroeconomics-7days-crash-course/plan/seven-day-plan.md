# 7 天宏观经济学 Crash Course 计划

每天固定 60 分钟。每一天都要产出一份短答案、一张易混对比卡和至少一张 recall card。

| Day | 主题 | A/B 优先级 | 当天必须会做的题 |
|---:|---|---|---|
| 1 | GDP 与国民收入核算 | A | 解释 GDP；区分 nominal GDP 和 real GDP；说明 GDP 为什么不等于福利。 |
| 2 | CPI、通胀与失业 | A | 解释 CPI 和 inflation rate；说明失业率分母；判断灰心工人的影响。 |
| 3 | AD-AS 模型 | A | 判断 AD/SRAS/LRAS 移动；说明产出和价格水平变化。 |
| 4 | 财政政策 | A | 用“G/T → AD → Y/P”写扩张性财政政策；说明 multiplier 和 crowding out。 |
| 5 | 货币政策 | A | 用“央行操作 → money supply / interest rate → I/C → AD”写政策链条。 |
| 6 | 稳定政策与 Phillips curve | B | 比较财政政策和货币政策；说明短期通胀—失业权衡。 |
| 7 | 总复习与模拟考试 | A/B | 完成 60 分模拟卷；按错题更新最终回忆卡。 |

## 每日固定流程

| 时间 | 动作 | 目的 |
|---:|---|---|
| 0-5 | Retrieval / Recall | 先回忆昨天内容，避免只看不记。 |
| 5-10 | Course map 定位 | 知道今天概念在全图里的位置。 |
| 10-25 | 核心讲解 | 只讲及格线必需内容。 |
| 25-35 | Feynman 复述 | 用自己的话解释，不许照抄定义。 |
| 35-45 | Exam practice | 写一段能得分的答案。 |
| 45-55 | Feedback | 标注得分点、漏点和混淆点。 |
| 55-60 | State update | 更新状态、错因、下一步。 |

## 推进规则

- 当天 quiz ≥ 60%：进入下一天，但保留错题 recall card。
- 当天 quiz 41-59%：下一天前 10 分钟补救当天主题。
- 当天 quiz ≤ 40%：下一天不推进新模型，先重讲定义和例题。
