# Day 4 — 政策干预、财政政策与乘数

## Goal

会用 AD-AS 写出扩张性/紧缩性政策的基本传导链条，并说明 fiscal policy、multiplier、automatic stabilizers 和 crowding out。

## 今日核心 terms

policy intervention, expansionary policy, contractionary policy, fiscal policy, government purchases, taxes, transfer payments, multiplier, automatic stabilizers, crowding out

## Day 3 开头修复

正式进入 Day 4 前，先做 5–8 分钟复查：

1. AD 右移时，短期真实产出 `Y` 和价格水平 `P` 怎么变。
2. 一个成本上升导致 `Y < Y*` 的情境中，没有政策干预时，长期 SRAS 如何调整。
3. 劳动参与率和就业人口比率的区别。

复查题题干保持中性，不提前出现曲线名称、移动方向、缺口类型或答案结果。

## Time Box

| Minutes | Activity | 具体动作 |
|---:|---|---|
| 0-8 | Repair recall | 用 3 道短题修复 Day 3 方向性错误与劳动参与率。 |
| 8-15 | Map | 把政策干预放到 AD-AS：政策短期通常先移动 AD，不是直接移动 LRAS。 |
| 15-30 | Core explanation | 用“定义—例子—易错点—考试写法”学习 fiscal policy、government purchases、taxes、transfer payments、multiplier、automatic stabilizers、crowding out。 |
| 30-40 | Visual AD-AS policy | 使用 `assets/diagrams/day3-policy-closing-output-gaps.png` 讲扩张性政策与紧缩性政策如何关闭缺口。 |
| 40-50 | Exam practice | 给一个经济情境，让学习者判断应使用哪类政策、AD 如何变、短期 Y/P 如何变、限制是什么。题干不提示答案方向。 |
| 50-57 | Feedback | 学习者作答后，再指出遗漏、混淆和可改进表达；必要时追加回忆卡。 |
| 57-60 | State update | 更新 `state/score-history.md`、`state/recall-deck.md`、`state/misconceptions.md`、`state/interest-ledger.md`、`state/next-action.md`。 |

## Visual Requirements

- 使用 `assets/diagrams/day3-policy-closing-output-gaps.png` 讲政策通过 AD 移动关闭缺口。
- 若重新讲 AD-AS 四种短期冲击，可使用 `assets/diagrams/day3-ad-sras-four-shocks.png`。
- 图像要插入对应解释附近，不只给文件名。
- 不使用复杂 ASCII 图作为主要讲解。

## 最低合格输出

1. 一段 120–180 字的考试答案：经济衰退时扩张性财政政策如何通过 AD 影响 `Y` 和 `P`，并说明一个限制。
2. 一组易混概念对比：government purchases vs transfer payments；multiplier vs crowding out；discretionary policy vs automatic stabilizers。
3. 至少一张 recall card。

## 不及格补救

- 如果定义写不准：先抄写术语表定义，再换成自己的话。
- 如果传导链条断裂：按“情境 → 政策工具 → C/G/I → AD → 短期 Y/P → 限制”重写。
- 如果把政策当成 LRAS 移动：回到图中说明短期稳定政策通常先改变 AD，只有提高长期生产能力的政策才可能影响 LRAS。
