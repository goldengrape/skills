# Day 7 — 总复习与模拟考试

## Goal

整合 GDP、CPI、失业、AD-AS、财政政策、货币政策和稳定政策，完成 60 分模拟卷。

## 今日核心 terms

GDP, CPI, unemployment, aggregate demand, aggregate supply, fiscal policy, monetary policy, Phillips curve, exchange rate

## Time Box

| Minutes | Activity | 具体动作 |
|---:|---|---|
| 0-5 | Recall | 不看笔记，写出昨天或已学概念的 3 个关键词；Day 1 写下你对宏观经济学的直觉理解。 |
| 5-10 | Map | 在 `course-map.md` 中定位今天主题：它回答“衡量、波动、政策、限制”中的哪一类问题。 |
| 10-25 | Core explanation | 用“定义—例子—易错点—考试写法”学习：GDP, CPI, unemployment, aggregate demand, aggregate supply, fiscal policy, monetary policy, Phillips curve, exchange rate。 |
| 25-35 | Feynman | 用 6 句话把今天主题讲给一个没学过经济学的人；必须包含 1 个生活例子。 |
| 35-45 | Exam practice | 完成 final-review/mock-exam.md 的学生可见题目；作答后再使用复习模板修正。 |
| 45-55 | Feedback | 学习者作答后，再指出遗漏、混淆和可改进表达；必要时追加回忆卡。 |
| 55-60 | State update | 更新 `state/score-history.md`、`state/recall-deck.md`、`state/misconceptions.md` 和 `state/next-action.md`。 |

## 最低合格输出

1. 一段 120-180 字的考试答案。
2. 一组易混概念对比：所有高频易混点：名义/实际、CPI/GDP deflator、AD/SRAS、财政/货币、短期/长期。
3. 至少一张 recall card。

## 不及格补救

- 如果定义写不准：先抄写一遍术语表定义，再换成自己的话。
- 如果传导链条断裂：按“政策/冲击 → 直接变量 → AD/SRAS/LRAS → 产出和价格 → 限制”重写。
- 如果例子不会举：用政府支出、油价上涨、央行降息、消费者信心下降四个常用例子。
