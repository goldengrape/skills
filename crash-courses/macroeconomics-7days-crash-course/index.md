# 宏观经济学 7 天 Crash Course

这是一个状态化教学 skill / Course Learning OKF。它不是静态学习计划，而是一个可以记录学习进度、错题、回忆卡、兴趣分支、图像资产和下一步动作的学习工作区。

## 你的设定

- 基础：0 基础
- 时间：7 天
- 每天：约 1 小时
- 时间策略：soft，除非学习者明确要求严格限时
- 目标：60 分及格优先
- 考试形式：未知，按“名词解释 + 简答 + 比较 + 小计算 + 小论述”混合训练

## 从哪里开始

1. 先读 `SKILL.md`，了解这个 skill 的执行规则。
2. 每次学习前读 `state/` 目录和 `teacher/teacher-notebook.md`。
3. 按 `state/next-action.md` 进入对应的 `plan/day-N.md`。
4. 涉及曲线、图像或均衡模型时，读 `assets/diagrams/index.md` 和 `teacher/visual-teaching-policy.md`。
5. 每次学习后更新 `sessions/`、`state/`、`teacher/teacher-notebook.md`，必要时更新图像索引。

## 常用入口

- 今日学习：`plan/day-1.md` 到 `plan/day-7.md`
- 每日测验：`quizzes/day-1-quiz.md` 到 `quizzes/day-7-quiz.md`
- 概念地图：`course-map.md`
- 优先级：`priority-map.md`
- 学习状态：`state/current-state.md`、`state/next-action.md`
- 兴趣分支：`state/interest-ledger.md`
- 图像索引：`assets/diagrams/index.md`
- 教师运行规则：`teacher/teaching-protocol.md`、`teacher/visibility-rules.md`、`teacher/visual-teaching-policy.md`
- 最后复习：`final-review/compressed-notes.md`、`final-review/mock-exam.md`
