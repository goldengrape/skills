# 宏观经济学 A/B/C 优先级

## A — 必须掌握

| 主题 | 为什么是 A | 最低合格答案必须包含 |
|---|---|---|
| GDP 与支出法 `Y=C+I+G+NX` | 高频名词解释和计算解释入口。 | GDP 定义、最终产品、境内生产、支出法四项。 |
| Nominal GDP vs Real GDP | 很容易考比较题。 | 名义用当年价格，实际用基期价格，实际更适合比较产出。 |
| CPI 与 Inflation | 宏观指标高频。 | CPI 是消费篮子价格指数，通胀率是价格水平增长率。 |
| Unemployment rate | 常与周期和政策连用。 | 失业率分子分母、劳动力定义、灰心工人问题。 |
| Aggregate Demand / Aggregate Supply | 政策分析核心图。 | AD、SRAS、LRAS 各自含义；冲击使曲线移动。 |
| Fiscal policy | 简答和论述高频。 | 政府支出、税收、乘数、crowding out。 |
| Monetary policy | 简答和论述高频。 | 央行、货币供给、利率、投资、AD 之间的链条。 |
| Recession stabilization | 综合题高频。 | 衰退时扩张性政策如何提高 AD，同时说明限制。 |

## B — 稳定加分

| 主题 | 为什么是 B | 最低合格答案必须包含 |
|---|---|---|
| Phillips curve | 能让政策题更完整。 | 短期通胀—失业权衡，长期受预期调整影响。 |
| Economic growth | 常见但可压缩。 | 长期增长来自生产率、资本、人力资本和技术。 |
| Automatic stabilizers | 写财政政策时很有用。 | 税收和转移支付自动缓冲衰退或过热。 |
| Exchange rate and net exports | 开放经济基础题。 | 本币贬值通常使出口更便宜、进口更贵，NX 可能上升。 |

## C — 7 天及格目标下暂缓

| 主题 | 暂缓原因 |
|---|---|
| 复杂 IS-LM 推导 | 没有课件要求时，一周内收益不如 AD-AS 和政策链条。 |
| 高级开放经济模型 | 及格线通常只需汇率、净出口、资本流动基础。 |
| 动态优化与理性预期模型细节 | 超出入门冲刺范围。 |
| 经济学流派史细节 | 只保留能服务政策题的观点差异。 |

## 调整规则

- 如果 Day 1 或 Day 2 测验低于 60%，Day 3 开始前必须补 GDP / CPI / unemployment。
- 如果 AD-AS 判断题低于 60%，不得进入政策论述，先补曲线移动方向。
- 如果政策题能写出工具但写不出传导链条，下一天开头加 10 分钟“工具 → 变量 → AD → 产出/价格”训练。
