# 资料与来源缺口

## 已用资料

当前没有用户上传教材、课件、老师重点或往年题。本 skill 使用常见入门宏观经济学课程框架生成，覆盖 GDP、CPI、失业、AD-AS、财政政策、货币政策、经济周期、菲利普斯曲线和开放经济基础。

## Source Gaps

- 缺少课程大纲。
- 缺少老师强调的章节。
- 缺少往年题。
- 缺少考试题型比例。
- 缺少是否需要计算题的信息。

## 后续替换规则

如果学习者上传课件或往年题，应立刻检查：

1. `priority-map.md` 是否需要重排。
2. `plan/day-N.md` 是否需要加入老师高频题。
3. `final-review/mock-exam.md` 是否要改成真实题型比例。
4. `state/plan-changes.md` 是否要记录本次调整。
