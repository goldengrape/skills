## 3. 今日考试型输出记录

### 3.1 CPI 与通胀率计算

表现：稳定。能正确计算 2024、2025、2026 年 CPI 和 2025、2026 年通胀率。

可保留版本：

> 以 2024 年为基准年，2024 年 CPI = 400/400×100 = 100；2025 年 CPI = 440/400×100 = 110；2026 年 CPI = 484/400×100 = 121。2025 年通胀率 = (110-100)/100×100% = 10%；2026 年通胀率 = (121-110)/110×100% = 10%。

### 3.2 CPI 为什么可能高估真实生活成本上涨

表现：稳定。能使用固定消费篮子和消费者替代行为解释替代偏误。

可保留版本：

> 固定篮子的 CPI 可能高估真实生活成本上涨，因为它假设消费者继续按原来的数量购买各类商品。但现实中，当某些商品相对变贵时，消费者会少买这些商品，多买相对便宜的替代品。因此，实际维持相似生活水平所需的支出可能低于固定篮子显示的支出，这就是替代偏误。

### 3.3 质量变化偏误

表现：稳定，且能主动设计更清楚的例子。

可保留版本：

> CPI 想衡量的是同等质量商品的价格变化，而不是只比较同名商品的价格。如果一台手机今年价格上涨，但电池、存储、摄像头和处理器都明显改善，那么观察到的价格上涨中，一部分可能反映质量提高，而不是真正的同质商品价格上涨。类似地，如果一罐蛋白粉价格从 100 元涨到 120 元，但蛋白含量从 50 克提高到 70 克，那么总价上涨不等于单位蛋白价格上涨。

### 3.4 失业率、劳动参与率与灰心工人

表现：失业率稳定，劳动参与率需要轻度复习。

可保留版本：

> 失业率 = 失业人数 / 劳动力 × 100%，其中劳动力 = 就业者 + 正在找工作的失业者。劳动参与率 = 劳动力 / 成年人口 × 100%。灰心工人因为已经停止找工作，不计入失业人数，也不计入劳动力。因此灰心工人增加时，官方失业率可能下降，但这不说明就业市场改善，因为下降可能来自退出劳动力市场，而不是更多人找到工作。

### 3.5 三类失业

表现：稳定。

可保留版本：

> 摩擦性失业来自找工作和岗位匹配需要时间，例如毕业生找第一份工作。结构性失业来自技能、行业或地区与岗位需求不匹配，例如新技术减少传统岗位后，原劳动者需要重新培训。周期性失业来自经济衰退和总需求不足，例如订单下降导致企业裁员。

## 5. 终测关键修正

终测中唯一明显错误是劳动参与率。

学生写成：

```text
劳动参与率 = 就业人数 / 成年人口 = 300 / 500 = 60%
```

正确应为：

```text
劳动力 = 就业者 + 正在找工作的失业者 = 300 + 50 = 350
劳动参与率 = 劳动力 / 成年人口 × 100% = 350 / 500 × 100% = 70%
```

纠正句：

> 劳动参与率的分子是劳动力，不是就业人数。就业人数 / 成年人口 更接近就业人口比率，不是劳动参与率。

## 6. 今日能独立解释的概念

- CPI 是固定消费篮子价格相对基准年的指数。
- 通胀率是 CPI 的百分比变化。
- CPI 上升通常意味着货币购买力下降。
- CPI 可能受到替代偏误、新产品偏误和质量变化偏误影响。
- CPI 与 GDP deflator 的区别：CPI 看居民消费篮子，GDP deflator 看境内生产的最终产品和服务价格。
- 失业率 = 失业人数 / 劳动力 × 100%。
- 劳动力 = 就业者 + 正在找工作的失业者。
- 劳动参与率 = 劳动力 / 成年人口 × 100%。
- 灰心工人不计入失业人数和劳动力。
- 失业率下降不一定代表就业市场改善。
- 摩擦性、结构性、周期性失业的直接原因不同。

### 7.1 CPI 和失业率为什么会影响科技股

学生主动提出：不清楚为什么失业率数据会特别影响科技股价格。

记录结论：

> CPI 和失业率不会机械地决定股价。市场更关心这些数据是否改变了对利率、经济需求和企业盈利的预期。CPI 高于预期，可能让市场预期央行维持高利率更久，从而压低成长股估值。失业率上升有双重含义：一方面可能代表经济变弱、盈利预期下降；另一方面也可能让市场预期降息，从而支持科技股估值。

### 7.2 CPI 是否也有 chained / chain-weighted 版本

学生把 Day 1 的 chain-weighted real GDP 与 Day 2 的 CPI 联系起来，追问 CPI 是否也有类似处理。

记录结论：

> 有。现实统计中存在 Chained CPI，例如美国的 C-CPI-U。它不是长期固定一个消费篮子，而是把相邻时期的消费结构变化连接起来，更好地反映消费者在相对价格变化后的替代行为。它主要缓解固定篮子带来的替代偏误，但不能单靠一个公式完全解决新产品、商品退出和质量变化问题。

对比记法：

| 指标 | 关注点 | chain 的作用 |
|---|---|---|
| chain-weighted real GDP | 真实产出增长 | 避免长期固定某一年价格权重导致真实产出失真。 |
| Chained CPI | 消费者生活成本 | 避免长期固定消费篮子权重导致生活成本上涨被高估。 |

### 7.3 CPI-U、CPI-W、C-CPI-U

记录结论：

| 指标 | 全称 | 核心意思 |
|---|---|---|
| CPI-U | Consumer Price Index for All Urban Consumers | 所有城市消费者价格指数，是媒体最常说的广义 CPI。 |
| CPI-W | Consumer Price Index for Urban Wage Earners and Clerical Workers | 城市工薪与文职人员消费者价格指数，是 CPI-U 覆盖人群的子集。 |
| C-CPI-U | Chained Consumer Price Index for All Urban Consumers | 覆盖人群接近 CPI-U，但使用 chained / Törnqvist 思路，更能反映替代行为。 |

注意点：

- CPI-W 不是工资指数，它仍然是消费者价格指数，只是覆盖人群更窄。
- CPI-U 与 CPI-W 的主要差别是覆盖人群不同，因此消费权重不同。
- C-CPI-U 的主要差别是计算方法和权重处理不同。

简化计算思路：

```text
某类商品价格变化 = 本月价格 / 上月价格
该类平均权重 = (上月支出份额 + 本月支出份额) / 2
本月总体价格变化 = 各类价格变化按平均支出份额做几何加权
本月 C-CPI-U = 上月 C-CPI-U × 本月总体价格变化
```

### 7.4 美国是否有州级 CPI

学生追问：加州和德州生活成本不同，美国是否按州单独计算 CPI，以及从哪里看。

记录结论：

> 美国 BLS 主要发布全国、区域、分区和部分都市区 CPI，并不是每个州都有一个完整、可直接比较的官方州级 CPI。加州、德州可以看对应都市区或区域 CPI。若要比较州际生活成本水平，不应直接比较 CPI 指数点位，而应看 BEA Regional Price Parities 等地区价格水平指标。

区分句：

```text
CPI：这个地区价格随时间涨了多少。
地区生活成本水平：这个地区相对另一个地区本来有多贵。
```

查看方向：

| 想看什么 | 更合适的数据 |
|---|---|
| 美国整体通胀 | 全国 CPI / CPI-U |
| 加州主要城市通胀 | Los Angeles、San Francisco、San Diego、Riverside 等都市区 CPI |
| 德州主要城市通胀 | Dallas-Fort Worth、Houston 等都市区 CPI |
| 区域通胀 | West、South 等区域 CPI |
| 州际生活成本高低 | BEA Regional Price Parities |
