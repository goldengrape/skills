# Manage Learning Control

## 1. Negotiate once, then proceed

Before creating or starting a course, explain L1-L9 and state the default: A-priority concepts target L6. Ask for target level, goal, time budget, materials, diagram preference, time policy, and barehand-checkpoint acceptance. If the user does not answer every item, continue with documented defaults in `learning-contract/index.md`.

## 2. Match assessment to target

- L4: recall without notes.
- L5: same-type application.
- L6: blind misuse-discrimination or flawed-answer check.
- L7: transfer or cross-day mixed scenario.
- L8: low-hint mixed or timed fluency.
- L9: teach, critique, design examples, or create.

## 3. Preserve productive friction

Keep the learner's work of recalling, selecting the model, explaining why, detecting misuse, and transferring. Remove tool friction such as file organization, diagram generation, formatting, and source indexing.

## 4. Record evidence

Every assessment row must include assistance mode and score type. Update `state/concept-mastery-state.md` and append detailed events to `state/assessment-evidence-ledger.md`. Do not claim stability above the evidence ceiling.

## 5. Run barehand checks

For L6+ targets, run a no-hint cross-day checkpoint every 2-3 learning days when feasible. Record as `barehand_score`.
