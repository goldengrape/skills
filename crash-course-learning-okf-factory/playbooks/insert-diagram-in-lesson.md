# Insert Diagram In Lesson

## Rule

Diagrams should appear in the teaching content near the concept they explain, not only as detached file links.

## Required Explanation Around a Curve Diagram

For curve lessons, include:

1. Axis labels and why they are set that way.
2. What the curve represents.
3. Why the slope has that direction.
4. What movement along the curve means.
5. What a whole-curve shift means.
6. How to compare old and new equilibrium points.

## Markdown Pattern

```markdown
![AD curve with left and right shifts](assets/diagrams/day-3-ad-curve-v1.png)
```

Then immediately explain the graph in student-visible language.
