# Day 7: PTAB, IPR/PGR, modern updates, synthesis, and final review

## Today’s Goal

能把授权后挑战和近年更新放回整张图，而不是把它们当成孤立新闻。

## Why This Matters for the Exam

本日内容对应课程 A/B 类主题，重点不是背术语，而是能在短事实中识别问题、拆分规则、避免混淆。

## 0-5 min — Recall

1. 今天涉及哪些关键词：IPR、PGR、PTAB、AI-assisted inventorship、design patent GUI/icon、fee schedule、synthesis？
2. 昨天内容中哪一个概念会影响今天判断？
3. 你最容易把今天主题和哪条规则混淆？

## 5-10 min — Map

先画一条小路径：

```text
facts → claim / source → legal gate → rule → application → uncertainty
```

今天只分析指定 gate；不要把所有专利法问题一次性混在一起。

## 10-25 min — Core Explanation

- IPR / PGR 是授权后挑战机制，和地区法院诉讼不同。
- IPR 的典型关注点与 patents / printed publications 下的 §102 / §103 更紧密。
- AI-assisted inventions 要拆成 eligibility、inventorship、disclosure、obviousness 等问题。
- Design patent 的 GUI/icon 更新提醒：design 与 utility 不是同一条规则线。
- 费用、MPEP、guidance 都可能更新；课程目标之一是知道去哪查。

## 25-35 min — Case / Source Link

阅读 `case-cards/core-case-cards.md` 中与今天主题相关的 1–3 张卡。只回答四件事：

1. 这个案子解决了什么问题？
2. 它限制了哪种直觉答案？
3. 它最容易被误读成什么？
4. 它如何改变你对今天事实题的分析？

## 35-48 min — Exam Practice

综合题：一个 AI 工具帮助工程师设计新型图标界面，同时生成一套控制方法。
1. 哪些问题属于 utility patent？
2. 哪些问题可能属于 design patent？
3. AI 参与会引出哪些 inventorship 或 disclosure 问题？
4. 若专利授权后被挑战，IPR / PGR 可能分别关注什么？
5. 哪些问题你必须查当前 USPTO guidance 后再回答？
