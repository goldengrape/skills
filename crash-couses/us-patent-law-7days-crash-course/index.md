# 课程包入口

建议从 `README.md` 开始。

## 快速入口

- `mission.md`：课程目标与边界。
- `course-map.md`：概念地图。
- `priority-map.md`：学习优先级。
- `resources.md`：资料入口。
- `plan/day-1.md`：第一天学习包。
- `state/next-action.md`：下一步动作。

## 主要目录

| 目录 | 用途 |
|---|---|
| `plan/` | 7 天学习包 |
| `quizzes/` | 每日测验题，学生可见 |
| `practice/` | 重点补强练习 |
| `case-cards/` | 核心判例卡 |
| `final-review/` | 期末复习与模拟题 |
| `state/` | 学习状态与误区追踪 |
| `sessions/` | 每日学习记录 |
| `teacher/` | 教师私有答案、rubric 与反馈材料 |
| `resources/` | 资料效力分层与更新追踪 |
| `package-meta/` | 版本、质量状态、设计依据 |
