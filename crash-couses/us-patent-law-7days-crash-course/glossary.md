# Glossary

| Term | Plain explanation |
|---|---|
| patent bargain | 公开换取有限期排他权的制度交换。 |
| right to exclude | 专利权的核心通常是排除他人制造、使用、销售、许诺销售或进口，而不是保证自己可以实施。 |
| utility patent | 保护实用发明的专利，通常是美国专利法学习主线。 |
| design patent | 保护制品外观设计的专利。 |
| provisional application | 临时申请，可建立较早申请日，但本身不会直接授权为 patent。 |
| nonprovisional application | 进入实质审查并可能授权的正式申请。 |
| claim | 权利要求，用文字界定专利保护范围。 |
| specification | 说明书，公开发明并支持 claims。 |
| patent eligible subject matter | §101 下可进入专利保护的主题类别及司法例外分析。 |
| judicial exception | 法院形成的例外，如自然规律、自然现象、抽象思想。 |
| Alice/Mayo framework | §101 分析框架：是否涉及司法例外，以及是否有足够的额外内容使 claim 合格。 |
| prior art | 现有技术，用于 §102 和 §103 分析。 |
| anticipation | 单一 prior art reference 公开 claim 每个要素，导致缺乏新颖性。 |
| PHOSITA | person having ordinary skill in the art，本领域普通技术人员。 |
| nonobviousness | §103 要求；即使没有被单一文献完全公开，也不能对 PHOSITA 显而易见。 |
| Graham factors | §103 分析中的基础事实框架。 |
| KSR | 强调常识、组合动机和灵活 obviousness 分析的最高法院判例。 |
| written description | 说明书显示发明人在申请日已占有所要求保护的发明。 |
| enablement | 说明书使 PHOSITA 无需过度实验即可实施 claimed invention。 |
| definiteness | claim 必须以合理确定性告知保护范围。 |
| claim construction | 解释 claim 文字含义的过程。 |
| direct infringement | 未经许可实施 claim 每个要素的侵权。 |
| doctrine of equivalents | 即使不字面落入 claim，也可能因实质等同构成侵权。 |
| IPR | inter partes review，PTAB 授权后挑战程序之一。 |
| PGR | post-grant review，授权后早期挑战程序之一。 |
| willfulness | 故意侵权相关概念，可影响 enhanced damages。 |
