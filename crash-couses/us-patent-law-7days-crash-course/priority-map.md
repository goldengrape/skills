# Priority Map

## A — Must Learn

| Topic | Why it matters | Common question form | Source evidence |
|---|---|---|---|
| Patent bargain and right to exclude | 所有规则都围绕“公开换排他权”展开。 | 解释专利制度目的。 | 35 U.S.C.; USPTO basics |
| Patent types and application posture | 不知道类型和流程，就会混淆实体法与程序法。 | 比较 utility / design / plant；provisional / nonprovisional。 | USPTO apply pages |
| §101 patent eligibility | 美国专利法高频难点，软件、生命科学、AI 都常出现。 | 用 Alice/Mayo 分析抽象思想或自然规律。 | §101; MPEP §2106 |
| §102 novelty and prior art | 判断是否被现有技术提前公开。 | 识别 anticipation / prior art。 | §102; MPEP §2131 |
| §103 nonobviousness | 专利性分析的核心门槛之一。 | 用 Graham / KSR 分析是否显而易见。 | §103; MPEP §2141 |
| §112 disclosure and claims | 说明书和 claim 决定专利能不能站住。 | 区分 written description / enablement / definiteness。 | §112; MPEP §§2163,2164,2173 |
| Claim construction | 侵权和有效性分析都要先解释 claim。 | 解释 Markman / Phillips 的意义。 | case law |
| Infringement basics | 专利权如何被执行。 | direct infringement / equivalents / indirect infringement。 | §271; case law |

## B — Should Learn

| Topic | Why it helps | When to study | Source evidence |
|---|---|---|---|
| Remedies | 理解侵权后的 injunction、damages、enhanced damages。 | Day 6–7。 | §§284–285; eBay; Halo |
| PTAB, IPR, PGR | 现代授权后挑战很重要。 | Day 7。 | §§311–329; USPTO PTAB |
| Prior art search | 帮助理解 §102 / §103。 | Day 3–4。 | USPTO Patent Search |
| AI-assisted inventions | 近年问题，适合作为现代更新入口。 | Day 7 或兴趣分支。 | USPTO / Federal Register |
| Design patent and GUI/icon guidance | 设计专利不应被 utility 主线掩盖。 | Day 7。 | 35 U.S.C. §§171–173; USPTO guidance |
| Key case card set | 用判例理解规则边界。 | 每天 1–3 张。 | casebook and court opinions |

## C — Can Skip or Only Recognize

| Topic | Reason for lower priority | Source evidence |
|---|---|---|
| Patent licensing and assignment | 重要但不是可专利性和侵权判断的前提。 | casebook background |
| FRAND / standard-essential patents | 偏高级竞争法和合同问题。 | advanced materials |
| ITC proceedings | 偏高级争议解决。 | advanced materials |
| International patent systems / PCT / EPO comparison | 容易拉宽范围。 | WIPO / EPO materials |
| Advanced damages models | 计算复杂，7 天内先学基础。 | case law |
| Full prosecution strategy | 偏执业训练。 | MPEP / practice guides |

## Rule

A topics receive explanation, retrieval, flawed-answer review, and exam-style practice. B topics receive brief explanation and selective practice. C topics are recognized only unless user materials later show they are exam-critical.
