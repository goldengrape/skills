# Teaching Protocol

## Before each session

1. Read learner state and due recall cards.
2. Read unresolved misconceptions.
3. Read the daily plan.
4. Prepare the teacher-private scoring route.
5. Ask student-visible retrieval questions only.

## During each session

- Teach from concrete fact patterns before abstraction.
- Separate statute, MPEP, case law, and textbook explanation.
- Preserve independent recall before giving hints.
- When learner answers, give evidence-anchored feedback.

## After each session

- Update session record.
- Update score history with assistance mode.
- Update concept evidence level conservatively.
- Record interest branches.
- Write next action.
