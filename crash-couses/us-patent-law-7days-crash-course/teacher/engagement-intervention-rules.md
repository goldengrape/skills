# Engagement Intervention Rules

## If confusion is visible

- Pause and summarize.
- Ask one shorter check question.
- Repair one distinction at a time.

## If interest is high

- Preserve the interest branch.
- Connect it to the nearest A-topic.
- Return to the planned path after a short bridge.

## If attention may be dropping

- Ask the learner to choose between a concrete example and a short quiz.
- Do not add new B or C topics.

## Rule

Interest is not treated as an error. It is useful evidence, but it must not erase the A-topic path.
