# Day 2 Feedback Samples

| Learner pattern | Diagnosis | Suggested feedback | Retest action |
|---|---|---|---|
| “No prior art, therefore eligible” | Uses §102 to answer §101 | “你正在用 novelty 回答 eligibility。请先写 statutory category，再写 possible judicial exception，再写 additional elements。” | Redo Alice/Mayo transfer mini-drill. |
| “It uses a computer, so eligible” | Treats generic computer as enough | “普通计算机实现不是自动通过。请指出 claim 是否改进计算机技术或其他技术过程。” | Ask for one pro-eligibility and one anti-eligibility fact. |
| “All software is abstract” | Overbroad rule | “软件 claim 需要 claim-level 分析。请区分普通数据处理和具体技术改进。” | Give industrial-oven control transfer question. |
| Strong rule, no facts | Definition-only answer | “规则对，但还没完成 application。请把 receiving、calculating、displaying 三个 claim elements 分别放进 Step 2A/2B。” | Require fact-labeled rewrite. |
