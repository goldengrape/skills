# Day 2 Answer Key

## Private scoring notes

Expected elements:
- §101 statutory categories: process, machine, manufacture, composition of matter.
- Judicial exceptions: laws of nature, natural phenomena, abstract ideas.
- Alice/Mayo: Step 2A directed to exception; Step 2B additional elements / inventive concept.
- Do not analyze novelty as substitute for eligibility.
- For app/software facts: generic data collection, calculation, and display are risk factors; technical improvement facts matter.

Strong answer pattern:
1. Start with statutory category.
2. Identify possible judicial exception.
3. Analyze whether claim integrates exception into practical application or adds significantly more.
4. Explicitly reserve §102 / §103 for separate analysis.

Common failures:
- “No prior art” used to answer §101.
- “Uses computer” used as automatic eligibility.
- All software declared ineligible without claim-level analysis.

## Feedback samples

| Learner pattern | Suggested feedback |

| Overconfident yes/no | “结论可以暂放后面。先列出支持、反对和不确定事实。” |

## Darwin R2 calibration expectations

For the calibration prompt, full-credit answers should separate the gates:

- §101 asks whether the claim is eligible subject matter: statutory category, judicial exception, and additional elements / practical application.
- §102 asks whether a single prior-art reference discloses every claim element as arranged or required.
- Prior art may appear in background facts, but lack of prior art is not a substitute for eligibility analysis.
