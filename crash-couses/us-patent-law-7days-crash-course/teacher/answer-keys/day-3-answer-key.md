# Day 3 Answer Key

## Private scoring notes

Expected elements:
- Prior art source must be legally available against the claim.
- Anticipation generally requires a single reference disclosing every claim element.
- Multiple references usually point toward §103 rather than §102 anticipation.
- Printed publication, public use, sale, and patent documents can raise distinct timing questions.
- Pfaff / Helsinn caution for on-sale bar.

Strong answer pattern:
1. Break claim into elements.
2. Match each element to a reference.
3. Ask whether all elements appear in one reference.
4. Flag timing / public availability uncertainty.

Common failures:
- Combining two references and calling it anticipation.
- Ignoring claim elements.
- Treating private knowledge as automatically prior art without legal analysis.
