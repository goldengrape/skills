# Flawed Answer Drills

## 使用规则

学习者先指出错误，再重写一个更稳妥的答案。不要先看 teacher 文件。

## Drill 1 — §101 / §102 confusion

> This software claim is patent eligible because no prior art discloses the exact app.

Questions:

1. 这句话混淆了哪两个问题？
2. 如果只讨论 §101，应改问什么？
3. 如果只讨论 §102，应改问什么？

## Drill 2 — Novelty / obviousness confusion

> The claim is novel because no single reference discloses every element, so it is nonobvious.

Questions:

1. 第一半句可能对应哪一条规则？
2. 为什么后半句不能自动推出？
3. 如何引入 PHOSITA？

## Drill 3 — Written description / enablement confusion

> The specification enables the invention because it proves the inventor possessed the full genus.

Questions:

1. 哪个词属于 written description？
2. 哪个词属于 enablement？
3. 为什么 genus claim 会放大 §112 风险？

## Drill 4 — Claim construction skipped

> Defendant uses a similar product, so there is infringement.

Questions:

1. 还缺少哪个前置步骤？
2. 为什么 claim term 的解释可能改变结果？
3. literal infringement 和 equivalents 分析为什么不能混在一起？

## Drill 5 — Remedy overclaim

> Patent owner won, so the court must issue a permanent injunction and treble damages.

Questions:

1. 哪个案子提醒 injunction 不是自动的？
2. 哪个案子提醒 enhanced damages 需要更具体的语境？
3. 如何改写成更谨慎的结论？

## Darwin R2 Drill 6 — Alice/Mayo shortcut

> This app is eligible because it is new and useful, and it runs on a phone.

Questions:

1. Which part wrongly uses §102 / utility-style reasoning?
2. Why is “runs on a phone” not automatically enough?
3. Rewrite the answer using statutory category → judicial exception → additional elements.

## Darwin R2 Drill 7 — KSR shortcut

> KSR says combinations are obvious, so combining the smart bottle and reminder app is obvious.

Questions:

1. Why is this too conclusory?
2. Name two facts that could support a reason to combine.
3. Name one fact that could cut against obviousness.

## Darwin R2 Drill 8 — full-scope enablement skipped

> The specification gives one working example, so the broad functional claim is enabled.

Questions:

1. What does “full scope” add to the analysis?
2. What facts would make one example insufficient?
3. How would you separately mention written description?
