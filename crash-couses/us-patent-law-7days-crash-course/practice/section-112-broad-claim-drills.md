# Day 5 Broad Claim Drills: written description / enablement / definiteness

## 使用规则

每题必须分开写：

1. claim scope 有多宽；
2. written description 问什么；
3. enablement 问什么；
4. definiteness 是否也可能出现；
5. 哪些事实会改变结论。

不要只写“说明书有一个例子，所以可以”。

## Drill A — Antibody genus

Specification discloses one antibody that blocks receptor X. Claim covers “all antibodies that bind receptor X and block signaling.”

### Questions

1. Claim scope 为什么宽？
2. Written description 风险是什么？
3. Enablement 风险是什么？
4. 哪些事实会让 claim 更稳？
5. 哪些事实会让 claim 更危险？

### Answer skeleton

```text
The claim is broad because it covers a functional genus: all antibodies with a blocking function, not merely the disclosed antibody. Written description asks whether the application shows possession of the claimed genus as of filing. Enablement asks whether a PHOSITA can make and use the full scope without undue experimentation. One example may be insufficient if the genus is large and unpredictable. The claim is stronger if the specification discloses representative species, common structural features, screening methods that are not unduly experimental, and guidance across the scope.
```

## Drill B — Software functional claim

Specification describes one rule-based fraud detection example for credit card transactions. Claim covers “any computer-implemented method for detecting fraudulent transactions by comparing transaction data to behavioral patterns.”

### Questions

1. 这是 broad functional claim 吗？为什么？
2. Written description 会问什么？
3. Enablement 会问什么？
4. Definiteness 可能在哪里出现？
5. 如何把 claim 改窄一点，使 §112 风险下降？

### Answer skeleton

```text
The claim is broad because it claims detection by function and covers many possible pattern-comparison methods. Written description asks whether the application shows the inventor possessed the claimed range of methods, not just one example. Enablement asks whether a PHOSITA can practice the full claimed range without undue experimentation. Definiteness may be implicated if terms like behavioral patterns fail to give reasonable certainty in context. A narrower claim could recite the specific features, data inputs, comparison rule, model limits, or transaction setting actually supported by the specification.
```

## Drill C — Mechanical range claim

Specification tests a coating thickness of 10 microns and 20 microns. Claim covers coating thickness from 1 to 500 microns for all outdoor machinery.

### Questions

1. Which part of the claim creates scope pressure?
2. How would written description and enablement differ?
3. What facts about predictability matter?
4. What dependent claim could reduce risk?

## Checklist for self-review

Before marking your answer complete, check:

- Did I name the §112 requirement separately?
- Did I compare examples in the specification to claim breadth?
- Did I say “full scope” when discussing enablement?
- Did I avoid treating inventor possession and making/using as identical?
- Did I mention uncertainty or missing facts?
