# Day 4 Fact Bank: PHOSITA / Motivation to Combine

## 使用规则

本文件用于 Day 4。学生不能只写“看起来很简单”或“KSR 允许组合”。必须从事实里选出能支持或削弱组合理由的材料。

## 1. PHOSITA profile checklist

回答 §103 时，先写一两句 PHOSITA 画像：

| Item | 要写什么 | 常见错误 |
|---|---|---|
| Field | 相关技术领域是什么 | 把普通消费者当 PHOSITA |
| Skill level | 当时一般技术人员会什么 | 用发明人自己的能力替代 PHOSITA |
| Time | 申请日前的知识状态 | 用发明成功后的 hindsight |
| Problem | 行业内面对什么设计问题 | 只写“想要更好产品” |
| Prior art access | 会合理看到哪些 references | 任意拼接不相关文献 |

## 2. Facts supporting obviousness

可作为支持 obvious 的事实类型：

| Fact type | How it helps | Example language |
|---|---|---|
| Design need | 行业内已有明确问题要解决 | “The prior art shows a known need for automatic hydration reminders.” |
| Market pressure | 市场推动相同方向改进 | “Consumer devices were already competing on health reminders.” |
| Predictable result | 组合后结果可预期 | “A sensor reading plus reminder algorithm would predictably notify the user.” |
| Finite options | 可选方案有限 | “The known options were timer-based, sensor-based, or manual input reminders.” |
| Known substitution | 替换元件已知且功能相同 | “Replacing manual input with an existing sensor was a known substitution.” |
| Common sense with facts | 普通知识有事实支撑 | “The record shows routine pairing of phone apps with wearable sensors.” |

## 3. Facts cutting against obviousness

可作为反对 obvious 的事实类型：

| Fact type | How it helps | Example language |
|---|---|---|
| Teaching away | prior art 建议不要这样做 | “Reference B warns that sensor-triggered reminders create false positives.” |
| Unpredictability | 结果不稳定或领域难预测 | “Hydration prediction varied by physiology and sensor placement.” |
| Incompatibility | 两个 references 技术上难以结合 | “A uses continuous hardware sensing while B assumes sparse manual inputs.” |
| Missing reason | 没有说明为什么会组合 | “The references can be combined in hindsight, but no pre-filing reason is identified.” |
| Secondary considerations | 客观证据支持非显而易见 | “Long-felt need and failure of others may matter if tied to the claimed features.” |
| Claim-specific feature | 关键 claim limitation 未被组合理由覆盖 | “The reason to combine does not explain the adaptive calibration limitation.” |

## 4. Answer skeleton

```text
Under §103, the question is whether the claimed combination would have been obvious to a PHOSITA before filing. The relevant prior art is [A] and [B]. The differences are [difference]. A reason supporting obviousness is [specific fact: design need / market pressure / predictable result]. A reason against obviousness is [teaching away / unpredictability / missing motivation / secondary consideration]. The main hindsight risk is [risk]. Therefore, the stronger conclusion is [tentative conclusion], subject to [missing fact].
```

## 5. Mini-drill

Fact pattern:

Reference A teaches a smart pill bottle with a weight sensor. Reference B teaches a calendar app that sends medication reminders. The claim combines the two and adds adaptive reminders when bottle weight does not change.

Write:

1. PHOSITA profile in two sentences.
2. One fact-supported obviousness argument.
3. One fact-supported nonobviousness argument.
4. One hindsight warning.
