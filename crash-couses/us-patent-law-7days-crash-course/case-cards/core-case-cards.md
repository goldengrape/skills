# Core Case Cards

## 使用方法

- 学生先用自己的话说：事实、问题、结论、为什么。
- 教师再用本文件校正。
- 不要求背完整案情；要求能把判例放回对应 doctrinal gate。

## §101 Patent Eligibility

### Diamond v. Chakrabarty

| Field | Content |
|---|---|
| Main issue | 人工改造的活体微生物是否可能属于 §101 subject matter。 |
| Exam-use takeaway | “自然存在”与“人为制造或改造”要分开。不是所有生命体都排除在专利之外。 |
| Common misuse | 误写成“只要是自然物都不可专利”或“所有生物技术都可专利”。 |
| Link to course | Day 2 statutory category / judicial exception。 |

### Bilski v. Kappos

| Field | Content |
|---|---|
| Main issue | 商业风险对冲方法是否可专利；machine-or-transformation test 的地位。 |
| Exam-use takeaway | machine-or-transformation 是有用线索，但不是 §101 唯一测试。 |
| Common misuse | 把 machine-or-transformation 写成唯一标准。 |
| Link to course | Day 2 abstract idea。 |

### Mayo Collaborative Services v. Prometheus

| Field | Content |
|---|---|
| Main issue | 基于体内代谢水平调整药物剂量的 claim 是否只是垄断自然规律。 |
| Exam-use takeaway | 自然规律加上常规、已知、普通步骤，通常不足以形成 inventive concept。 |
| Common misuse | 把 Mayo 当成 §102 novelty 案；它主要是 §101 eligibility 案。 |
| Link to course | Day 2 diagnostic method comparison。 |

### Association for Molecular Pathology v. Myriad Genetics

| Field | Content |
|---|---|
| Main issue | 分离出来的自然 DNA 与 cDNA 的可专利性区别。 |
| Exam-use takeaway | 发现自然存在的 DNA 序列不等于发明；cDNA 的分析要看是否具有非自然产生的特征。 |
| Common misuse | 写成“所有 DNA 都不能专利”或“分离出来就能专利”。 |
| Link to course | Day 2 natural product。 |

### Alice Corp. v. CLS Bank

| Field | Content |
|---|---|
| Main issue | 抽象金融中介结算思想用普通计算机实现，是否足以通过 §101。 |
| Exam-use takeaway | 不能只说“在电脑上执行”；要问 claim 是否 directed to abstract idea，以及额外要素是否显著更多。 |
| Common misuse | 把所有软件一概判为不可专利；或者认为用了计算机就自动通过。 |
| Link to course | Day 2 software and app fact patterns。 |

## §102 Novelty

### Pfaff v. Wells Electronics

| Field | Content |
|---|---|
| Main issue | on-sale bar 何时触发；发明是否 ready for patenting。 |
| Exam-use takeaway | 销售或要约与“ready for patenting”结合分析。 |
| Common misuse | 只看是否已经生产出实物。 |
| Link to course | Day 3 prior art / on-sale bar。 |

### Helsinn Healthcare v. Teva

| Field | Content |
|---|---|
| Main issue | AIA 后，保密销售是否仍可能触发 on-sale bar。 |
| Exam-use takeaway | AIA 没有把 on-sale bar 改成只限公开销售。 |
| Common misuse | 以为 AIA 后秘密销售一定安全。 |
| Link to course | Day 3 AIA caution。 |

## §103 Nonobviousness

### Graham v. John Deere

| Field | Content |
|---|---|
| Main issue | 非显而易见性应怎样分析。 |
| Exam-use takeaway | 看 prior art 范围和内容、claim 与 prior art 差异、PHOSITA 水平、secondary considerations。 |
| Common misuse | 只凭“感觉简单”判断 obviousness。 |
| Link to course | Day 4 baseline framework。 |

### KSR v. Teleflex

| Field | Content |
|---|---|
| Main issue | 是否必须有严格 teaching-suggestion-motivation 才能认定 obvious。 |
| Exam-use takeaway | 分析应灵活，可考虑 common sense、market pressure、predictable variation，但仍需解释理由。 |
| Common misuse | 写成“只要能组合就 obvious”。 |
| Link to course | Day 4 combination analysis。 |

## §112 Disclosure and Claims

### Ariad v. Eli Lilly

| Field | Content |
|---|---|
| Main issue | written description 是否是独立于 enablement 的要求。 |
| Exam-use takeaway | written description 要问申请日是否显示 inventor possession。 |
| Common misuse | 把“能做出来”直接等同于 written description 充分。 |
| Link to course | Day 5 written description vs enablement。 |

### Nautilus v. Biosig

| Field | Content |
|---|---|
| Main issue | claim definiteness 的标准。 |
| Exam-use takeaway | claim 需以 reasonable certainty 告知本领域技术人员发明范围。 |
| Common misuse | 认为只要能猜出大概意思就 definite。 |
| Link to course | Day 5 claim clarity。 |

### Amgen v. Sanofi

| Field | Content |
|---|---|
| Main issue | 宽泛 genus claim 是否被充分 enable。 |
| Exam-use takeaway | claim 范围越宽，对 enablement 支持要求越高；少量例子未必支撑整个属。 |
| Common misuse | 认为给几个 working examples 就能支持任意宽的 claim。 |
| Link to course | Day 5 scope matching。 |

## Claim Construction, Infringement, Remedies

### Markman v. Westview Instruments

| Field | Content |
|---|---|
| Main issue | claim construction 由法官还是陪审团决定。 |
| Exam-use takeaway | claim meaning 是专利诉讼中的核心前置问题，通常由法院解释。 |
| Common misuse | 直接跳到侵权，不先解释 claim term。 |
| Link to course | Day 6 claim construction。 |

### Phillips v. AWH

| Field | Content |
|---|---|
| Main issue | 如何用 claim language、specification、prosecution history 等解释 claim。 |
| Exam-use takeaway | claim terms 要放在 specification 和本领域语境中理解。 |
| Common misuse | 脱离说明书只查字典。 |
| Link to course | Day 6 intrinsic evidence。 |

### Warner-Jenkinson v. Hilton Davis

| Field | Content |
|---|---|
| Main issue | doctrine of equivalents 的现代限制。 |
| Exam-use takeaway | 即使没有 literal infringement，也可能有 equivalents，但不能吞掉 claim 限制。 |
| Common misuse | 把 equivalents 当成“差不多就侵权”。 |
| Link to course | Day 6 infringement。 |

### eBay v. MercExchange

| Field | Content |
|---|---|
| Main issue | 专利侵权后是否自动永久禁令。 |
| Exam-use takeaway | injunction 需适用传统 equitable factors，不自动授予。 |
| Common misuse | 写成“胜诉必有禁令”。 |
| Link to course | Day 6 remedies。 |

### Halo Electronics v. Pulse Electronics

| Field | Content |
|---|---|
| Main issue | enhanced damages 与 willful infringement。 |
| Exam-use takeaway | 增强赔偿强调 egregious infringement behavior 和法院裁量。 |
| Common misuse | 把所有侵权都写成三倍赔偿。 |
| Link to course | Day 6 remedies。 |
