# Day 3: 感觉系统与脊髓定位

## Today's Goal

完成 **感觉系统与脊髓定位** 的定位推理训练。作答时先定位解剖层级，再说明证据，不急着写疾病名称。

## Why This Matters for the Exam

考试题常把多个体征放在一起。如果只凭一个关键词作答，容易把脑干写成半球、把脊髓写成周围神经、把肌病写成神经根病。

## 0-5 min — Recall

不用笔记回答：

1. 昨天最容易混淆的一组定位是什么？
2. 今天主题中最重要的侧别或层级线索是什么？
3. 遇到不确定题目时，先找哪个反证？

## 5-10 min — Map

今天的位置：`course-map.md` → `感觉平面、感觉分离、半切、前脊髓、中央脊髓、圆锥/马尾` → 病例作答 → 状态记录。

## 10-25 min — Core Explanation

本节只讲考试所需的最小定位规则。重点看：

- 感觉平面是脊髓定位的强线索；手套袜套样分布更支持长度依赖性周围神经病。
- 同侧 UMN 无力和深感觉下降，伴对侧痛温觉下降，支持半侧脊髓病变。
- 双侧痛温觉受损、运动受损、后索相对保留，提示前脊髓综合征方向。
- 鞍区感觉、括约肌、疼痛分布和反射改变帮助区分圆锥与马尾。

## 25-35 min — Feynman Task

学生提示：

```text
用自己的话解释：感觉平面和感觉分离为什么能把定位从“周围神经”拉回到“脊髓”？请用一个小病例说明。
```

## Diagram Cue

进入病例前，先打开 `assets/diagrams/index.md` 中对应图示，用 30 秒确认病灶层级和侧别关系。

## 35-50 min — Exam Practice

先独立作答，不读取教师侧答案。每题都按这个格式写：

```text
1. 定位结论：
2. 支持证据 A：
3. 支持证据 B：
4. 我排除的第一个错误定位：
5. 排除理由：
6. 还需补充的一个查体/病史：
```

### DAY3-CASE-A: 典型题

```text
患者右下肢痉挛性无力，右侧深感觉下降，左侧痛温觉下降。请定位病灶侧别和层级。
```
### DAY3-CASE-B: 反例题

```text
患者双足麻木逐渐上行，呈手套袜套样分布，踝反射减弱，没有明确胸腹部感觉平面。请说明为什么不应优先写脊髓横贯性病变。
```

## 50-56 min — Feedback
