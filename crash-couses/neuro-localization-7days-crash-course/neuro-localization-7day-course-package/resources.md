## Source Rules

1. 只引用 source_id 和课程化概括，不复制大段原文。
2. 题目均为自写教学模拟病例，避免版权问题。
3. 权威资料用于确定术语、定位路径和医学边界。
4. 若未来加入学校材料，应放入 `overlays/school-specific/`，不改写通用核心包。
