# Brainstem and Cranial Nerve Localization Module

## Purpose

本模块训练脑干定位，尤其是“同侧脑神经体征 + 对侧长束体征”的组合。脑干题的危险在于：学生只看肢体无力侧别，把它误写成大脑半球。

## Core Rule: 交叉性体征优先考虑脑干

脑神经核团和脑神经束多在脑干同侧表现；皮质脊髓束在延髓下端交叉，所以脑干病灶常造成病灶同侧脑神经体征和对侧肢体 UMN 体征。

## Brainstem Level Hints

| Level | Cranial nerve clue | Long tract clue | 常见迷惑点 |
|---|---|---|---|
| Midbrain | III palsy, ptosis, pupil, vertical gaze | contralateral weakness | 只写动眼神经病，漏掉长束 |
| Pons | V, VI, VII, horizontal gaze, facial palsy | contralateral weakness/sensory loss | 把周围性面瘫当作孤立面神经病 |
| Medulla | IX, X, XII, dysphagia, hoarseness, tongue | contralateral body signs/crossed sensory | 把吞咽构音问题只写成肌病 |

## Worked Example 1: 脑桥交叉性体征

题干：右眼外展受限，右侧周围性面瘫，左侧肢体无力，左侧 Babinski 阳性。

作答链条：

```text
定位结论：右侧脑桥病变方向，累及 VI/VII 相关结构和右侧锥体束。
支持证据：右侧脑神经体征为病灶同侧；左侧肢体 UMN 体征为交叉前长束受累。
排除理由：左侧大脑半球不能解释右侧 VI/VII 核性或核下性体征；孤立面神经病不能解释对侧 Babinski。
```

## Worked Example 2: 面瘫类型改变定位

题干 A：左侧口角歪斜，但额纹保留、闭眼可，右侧肢体无力。可能是右侧皮质脊髓/皮质延髓通路。

题干 B：左侧额纹消失、闭眼不能，右侧肢体无力，右侧 Babinski 阳性。要警惕左侧脑桥交叉性体征。

关键区别：中枢性面瘫主要累及对侧下部面肌；周围性面瘫累及同侧上、下面肌。若周围性面瘫合并对侧长束体征，定位要回到脑干。

## Failure Cases

1. **只按肢体无力定位。** 脑干题常故意用肢体侧别诱导半球答案。
2. **把眼球运动障碍当眼科问题结束。** 合并长束体征时，它是脑干定位线索。
3. **没有说明侧别。** 脑干题必须写清病灶侧、脑神经侧、肢体侧的关系。

## Check Yourself

每遇到脑神经 + 肢体题，先问：

```text
脑神经体征是哪一侧？肢体长束体征是哪一侧？二者是否交叉？
```
