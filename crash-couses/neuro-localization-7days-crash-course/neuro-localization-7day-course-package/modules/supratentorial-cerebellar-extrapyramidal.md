# Supratentorial, Cerebellar and Extrapyramidal Module

## Purpose

本模块训练大脑半球、小脑、前庭和基底节定位。它的重点不是记住所有脑叶功能，而是把“皮层功能线索”和“非锥体束运动异常”从普通无力题中分离出来。

## Core Rule: 皮层功能能把定位拉向半球

单纯偏瘫只能说明对侧 UMN 通路受累，不能稳定定位到半球。若同时出现失语、忽视、同向偏盲、皮质感觉障碍、癫痫样起病等，半球或皮层/皮层下定位才更稳。

## High-Yield Patterns

| Pattern | Localization thought | Useful discriminator |
|---|---|---|
| 右利手 Broca 型失语 + 右偏瘫 | 左优势半球额叶/岛盖附近 | language + motor |
| 左侧忽视 + 左偏瘫 | 右非优势顶叶相关网络 | attention deficit |
| 同向偏盲 | 视放射/枕叶或后部通路 | 是否合并语言、忽视、运动 |
| 共济失调但肌力基本正常 | 小脑或小脑通路 | coordination > strength |
| 静止性震颤 + 强直 | 基底节环路 | extrapyramidal pattern |

## Worked Example 1: 失语把定位拉向优势半球

题干：右利手患者表达不流利，理解相对保留，右下部面瘫和右上肢无力。

作答链条：

```text
定位结论：左侧优势半球额下回/额叶-岛盖周围语言运动网络，可能累及邻近运动皮层或皮质下通路。
支持证据：右利手多为左优势半球；非流利表达支持 Broca 区相关网络；右侧面-上肢运动体征支持左侧运动系统。
排除理由：不能只写构音障碍，因为语言生成受损；不优先写孤立内囊，因为有皮层语言线索。
```

## Worked Example 2: 共济失调不是肌力下降

题干：患者走路不稳，指鼻试验不准，意向性震颤，肌力基本正常，无明显感觉平面。

定位思路：主要问题是协调障碍而不是力量输出不足，优先考虑小脑或小脑通路。若伴眩晕、眼震、吞咽构音或长束体征，要进一步区分中枢前庭/脑干小脑通路；若只有耳鸣听力下降和短暂眩晕，可考虑周围前庭线索。

## Failure Cases

1. **把构音障碍当失语。** 构音障碍是发音执行问题，语言理解和内容可正常。
2. **把共济失调当肌无力。** 小脑题常有“站不稳”“辨距不良”，不是反射和 Babinski 主导。
3. **把所有震颤写成小脑。** 静止性震颤、强直和运动迟缓更偏基底节环路。
