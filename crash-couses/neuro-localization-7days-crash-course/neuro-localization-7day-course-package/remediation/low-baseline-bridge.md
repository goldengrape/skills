# Low-Baseline Bridge

## When to Use

Use this before Day 1 practice if the learner does any of the following:

```yaml
trigger_conditions:
  - writes a disease name before anatomical level
  - reverses hemiparesis lesion side
  - cannot name UMN vs LMN evidence
  - omits exclusion reasoning in two consecutive answers
```

## The 4-Line Localization Skeleton

Every answer must start with four lines:

```text
1. 体征类型：UMN / LMN / 感觉平面 / 脑神经 / 皮层功能 / 小脑 / 周围模式
2. 神经轴层级：半球 / 脑干 / 脊髓 / 根-丛-周围神经 / NMJ / 肌肉
3. 支持证据：至少 2 条
4. 排除理由：至少 1 条
```

## Side Rule for Weak Learners

```text
肢体 UMN 体征在哪一侧？
→ 病灶通常在锥体交叉以上的对侧通路。
→ 但必须继续找：皮层线索、脑干交叉体征、脊髓感觉平面。
```

## Three Anchor Examples

### Example 1: Left UMN signs

```text
左侧偏瘫 + 左 Babinski 阳性
→ 左侧 UMN 体征
→ 病灶在右侧锥体束通路、锥体交叉以上
→ 还不能直接写右半球；需查失语/忽视/偏盲、脑神经交叉体征、感觉平面。
```

### Example 2: Crossed sign

```text
右侧周围性面瘫 + 左侧 Babinski
→ 右侧脑神经 LMN 体征 + 左侧长束体征
→ 右侧脑干，常考虑脑桥方向
→ 排除左半球，因为左半球不能解释右侧核性/核下性面瘫。
```

### Example 3: Stocking-glove pattern

```text
双足麻木上行 + 踝反射减弱 + 无感觉平面
→ 远端对称周围多发神经病
→ 排除脊髓，因为没有感觉平面、UMN 体征、括约肌线索。
```

## Exit Check

Learner may proceed only after answering all three prompts with lesion side, level, evidence and exclusion.
