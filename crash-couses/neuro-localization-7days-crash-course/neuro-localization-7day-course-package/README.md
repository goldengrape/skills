# 7 天速通神经内科定位诊断课程包

这是一个单独整理后的可运行课程包，用于医学生考前复习。课程目标不是完整覆盖神经病学，而是在 7 天内训练常见神经定位诊断题的推理路径。

## 使用顺序

1. 读 `mission.md`，确认课程目标和边界。
2. 读 `course-map.md` 与 `priority-map.md`，了解 7 天主线和 A/B/C 优先级。
3. 每天按 `plan/day-1.md` 到 `plan/day-7.md` 执行。
4. 每天完成 `quizzes/day-X-quiz.md` 后，再查看教师答案。
5. 每天结束后更新 `state/score-history.md`、`state/misconceptions.md` 和 `state/next-action.md`。
6. Day 7 使用 `final-review/mock-exam.md` 做完整模拟。

## 学生不要提前查看

以下文件供教师或自学复盘时使用，答题前不要打开：

- `teacher/answer-keys/`
- `teacher/quiz-answer-keys/`
- `teacher/rubrics/`

## 课程资料模式

本课程包仅基于网上可查的权威开放资料整理，不使用具体学校课件、老师重点或历史题库。因此它适合作为通用考前复习包，不是押题包。

## 医学边界

本课程只用于医学学习和考试复习，不用于真实患者诊断、治疗或分诊决策。
