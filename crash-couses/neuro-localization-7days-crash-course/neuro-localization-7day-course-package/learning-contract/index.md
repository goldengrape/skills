## Learning Stages

| Level | Meaning | Evidence required in this course |
|---|---|---|
| L1 | recognition | Recognize the term in a prompt. |
| L2 | recall | State a definition without notes. |
| L3 | explanation | Explain the idea in plain language. |
| L4 | routine use | Apply it to a familiar case. |
| L5 | comparison | Distinguish it from a nearby concept. |
| L6 | misuse discrimination | Detect a flawed localization and explain the error. |
| L7 | transfer | Apply it to a new mixed case. |
| L8 | strategy | Choose an efficient reasoning path under time pressure. |
| L9 | teaching | Teach the distinction and design a test case. |

## AI Diet

- guided: tutor gives structure.
- semi_guided: tutor gives a limited hint.
- blind: learner answers before any hint.
- barehand: learner answers without notes, hints, or options.

A-priority concepts require blind or barehand evidence plus a misuse check before being treated as stable. Barehand checks occur every 2-3 sessions.
