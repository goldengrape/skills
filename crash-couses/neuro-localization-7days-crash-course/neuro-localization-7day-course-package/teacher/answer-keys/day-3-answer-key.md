## DAY3-CASE-A

```yaml
teacher_private:
  case_id: DAY3-CASE-A
  localization_conclusion: "右侧半脊髓病变，Brown-Séquard 型定位。"
  supporting_evidence:
    - 右下肢痉挛性无力支持右侧皮质脊髓束受累。
    - 右侧深感觉下降支持右侧后索受累。
    - 左侧痛温觉下降提示对侧脊髓丘脑束受累，符合脊髓内交叉后的侧别关系。
  exclusion_reasoning:
    - 不支持单一神经根病，因为同时有长束 UMN 和分离性感觉受损。
    - 不应定位到左侧病灶，因为运动和深感觉侧别指向右侧半脊髓。
  common_mistakes:
    - 把痛温觉侧别当成病灶侧。
    - 没有解释感觉分离。
    - 写成“周围神经病”。
  score_points:
    - item: 定位层级
      points: 3
    - item: 支持证据
      points: 3
    - item: 排除理由
      points: 2
    - item: 需要补充的查体或病史
      points: 2
  remediation:
    - 先复述题干体征，不急着写病名。
    - 用“定位结论—支持证据—排除理由—补充线索”的四格格式重答一遍。
```

## DAY3-CASE-B

```yaml
teacher_private:
  case_id: DAY3-CASE-B
  localization_conclusion: "远端对称性周围多发神经病模式，而不是优先脊髓横贯性病变。"
  supporting_evidence:
    - 手套袜套样分布是长度依赖性周围神经受累常见模式。
    - 踝反射减弱支持周围神经/LMN 成分。
    - 没有明确感觉平面、UMN 体征或括约肌线索。
  exclusion_reasoning:
    - 脊髓横贯性病变通常更期待感觉平面、双侧 UMN 体征和括约肌异常。
    - 不能把“从脚开始上行”误读成脊髓平面上移。
  common_mistakes:
    - 把手套袜套样分布当成感觉平面。
    - 忽略踝反射减弱。
    - 没有追问 Babinski、肌张力、尿潴留。
  score_points:

      points: 3
    - item: 排除理由
```
