## DAY1-CASE-A

```yaml
teacher_private:
  case_id: DAY1-CASE-A
  localization_conclusion: "右侧锥体束/上运动神经元通路病变，位于锥体交叉以上；若无脑神经交叉体征和脊髓感觉平面，优先考虑右侧幕上或内囊-皮层下通路。"
  supporting_evidence:
    - 左侧肢体无力提示运动通路受累。
    - 左侧腱反射活跃和 Babinski 阳性支持上运动神经元。
    - 无明显肌萎缩不支持主要 LMN/周围神经病变。
  exclusion_reasoning:
    - 不能直接写病名，如脑梗死；题目只要求定位。
    - 不能仅凭偏瘫就锁定大脑半球，还要找皮层功能线索、脑神经交叉体征和感觉平面。
  common_mistakes:
    - 把定位诊断写成“脑梗”。
    - 忽略 Babinski，把它当周围神经病。
    - 没说明还需查失语、忽视、偏盲、脑神经和感觉平面。
  score_points:
    - item: 定位层级
      points: 3
    - item: 支持证据
      points: 3
    - item: 排除理由
      points: 2
    - item: 需要补充的查体或病史
      points: 2
  remediation:
    - 先复述题干体征，不急着写病名。
    - 用“定位结论—支持证据—排除理由—补充线索”的四格格式重答一遍。
```

## DAY1-CASE-B

```yaml
teacher_private:
  case_id: DAY1-CASE-B
  localization_conclusion: "定位尚不能确定为右侧大脑半球；需要先判断面瘫类型、是否有皮层功能受损、是否有交叉性脑神经体征。"
  supporting_evidence:
    - 左侧肢体无力可以来自右侧锥体束不同层级。
    - 口角歪斜若为中枢性下部面瘫，可支持右侧半球/内囊；若合并同侧周围性面瘫和对侧肢体无力，则转向脑干。
  exclusion_reasoning:
    - 不能把“偏瘫”当成半球的同义词。
    - 不能忽略面瘫是中枢性还是周围性。
  common_mistakes:
    - 一看到偏瘫就写对侧半球。
    - 不补查额纹、闭眼、眼球运动、语言、忽视、偏盲。
  score_points:
    - item: 定位层级
      points: 3
    - item: 支持证据
      points: 3
    - item: 排除理由
      points: 2
    - item: 需要补充的查体或病史
      points: 2
  remediation:
    - 先复述题干体征，不急着写病名。
    - 用“定位结论—支持证据—排除理由—补充线索”的四格格式重答一遍。
```
