## DAY6-CASE-A

```yaml
teacher_private:
  case_id: DAY6-CASE-A
  localization_conclusion: "长度依赖性远端对称性周围多发神经病。"
  supporting_evidence:
    - 双足麻木逐渐上行和远端感觉下降符合手套袜套样分布。
    - 踝反射减弱常见于周围神经受累。
    - 近端肌力尚可，不像典型近端肌病。
  exclusion_reasoning:
    - 不支持脊髓病变：缺少感觉平面、UMN 体征和括约肌线索。
    - 不支持神经肌接头病：有感觉异常和反射改变。
  common_mistakes:
    - 把周围神经病写成感觉平面。
    - 忽略感觉受损而写 NMJ。
    - 只写“末梢神经炎”不说明定位层级。
  score_points:
    - item: 定位层级
      points: 3
    - item: 支持证据
      points: 3
    - item: 排除理由
      points: 2
    - item: 需要补充的查体或病史
      points: 2
  remediation:
    - 先复述题干体征，不急着写病名。
    - 用“定位结论—支持证据—排除理由—补充线索”的四格格式重答一遍。
```

## DAY6-CASE-B

```yaml
teacher_private:
  case_id: DAY6-CASE-B
  localization_conclusion: "肌肉层级病变方向，表现为近端肌病模式；需与 NMJ 和周围神经病区分。"
  supporting_evidence:
    - 上楼和梳头困难提示骨盆带、肩带近端肌无力。
    - 感觉正常支持肌肉或 NMJ，而非周围多发神经病。
    - 腱反射早期保留更支持肌病方向。
  exclusion_reasoning:
    - 周围神经病更常有远端感觉异常和反射减弱。
    - NMJ 更强调波动性、易疲劳、眼睑下垂/复视等，肌病更稳定地近端无力。
  common_mistakes:
    - 看到无力就写神经根。
    - 没有注意感觉正常。
    - 没有区分肌病和 NMJ。
  score_points:
    - item: 定位层级
      points: 3
    - item: 支持证据
      points: 3
    - item: 排除理由
      points: 2
    - item: 需要补充的查体或病史
      points: 2
  remediation:
    - 先复述题干体征，不急着写病名。
    - 用“定位结论—支持证据—排除理由—补充线索”的四格格式重答一遍。
```
