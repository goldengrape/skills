# Answer Templates

## 定位简答模板

```text
病灶最可能位于【解剖层级/侧别】。依据是：第一，【体征 1】提示【结构/通路】受累；第二，【体征 2】提示【同侧/对侧/双侧关系】；第三，【阴性或不支持线索】使【常见误判】可能性较低。因此定位优先考虑【结论】，病因诊断需结合病程和检查。
```

## 脑干模板

```text
这是交叉性体征：同侧第【脑神经】相关表现，加对侧【长束】表现，优先定位于【中脑/脑桥/延髓】的【侧别】。
```

## 脊髓模板

```text
有【感觉平面/双侧长束/括约肌】线索，优先定位脊髓。根据【痛温/深感觉/运动】组合，考虑【半切/前索/中央/圆锥/马尾】模式。
```

## 周围定位模板

```text
根据分布判断：若符合皮节和肌节，考虑神经根；若跨多根多神经，考虑神经丛；若符合单一神经，考虑单神经；若远端对称，考虑多发周围神经；若疲劳波动且感觉正常，考虑 NMJ；若近端无力且感觉正常，考虑肌肉。
```

## Forced Exclusion Template for Weak-Baseline Learners

```text
1. 定位结论：层级 + 侧别。
2. 支持证据 A：来自哪一个体征？
3. 支持证据 B：来自哪一个体征？
4. 我排除的错误定位：例如半球/脑干/脊髓/周围/NMJ/肌肉。
5. 排除理由：题干缺少什么，或出现了什么反证？
6. 还要补充：一个最能分层的查体或病史。
```

评分提醒：如果没有排除理由，即使定位结论正确，也不能认为定位推理稳定。
