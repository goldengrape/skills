# 目的

在生成最终答复草稿前，检查 OA 分析和答复方案是否触发领域 hard gate。若触发 hard gate，应回到对应上游步骤修复，不得直接进入最终文本。

# 使用位置

必须在以下位置执行：

1. `patent-oa-response` 第 1 步案卷完整性检查后；
2. 第 5 步形成当前答复候选后；
3. 第 7 步胜率评估后；
4. 第 9 步二次评估和选择后；
5. 第 10 步最终文本生成前。

# Hard Gate 清单

| ID | 检查项 | 修复入口 |
|---|---|---|
| HG-01 | 未读关键文件却作确定性判断；包括未读取审查员补充引证文件却确定反驳其公开内容。 | 回到文件接收、事实底稿或 claim chart。 |
| HG-02 | 权利要求修改缺少原申请支持位置。 | 回到事实底稿和修改方案。 |
| HG-03 | 遗漏独立拒绝理由、异议或形式缺陷。 | 回到 OA 拆解。 |
| HG-04 | 事实、判断、策略混杂；或把推断写成明示公开。 | 回到对应输出，按三类内容重写。 |
| HG-05 | 引用段落、页码、附图或对比文件内容无法核对；包括审查员补充证据缺件。 | 回到证据规则和原文核对。 |
| HG-06 | 输出“必然授权”等承诺性结论。 | 回到法律边界并改成风险区间。 |
| HG-07 | 起草、审稿或 A/B 修订自行输出最终胜率。 | 回到胜率唯一出口规则。 |
| HG-08 | 法域错配或法域未确认却使用具体程序路径。 | 回到文件接收，确认法域和程序阶段。 |
| HG-09 | 最终草稿新增未模拟、未评估的核心论点或限定。 | 回到 A/B 修订、二次模拟和二次评估。 |
| HG-10 | 复用已被审查员明确反驳的申请人论点，且没有新增证据、新限定或重构后的技术问题支撑。 | 回到 OA 拆解和答复稿审查，删除或重写该论点。 |
| HG-11 | 只从 OA 首页“对比文件表”抽取证据，遗漏正文中被审查员用于证明常规技术手段、公知常识或组合启示的公开号、专利号、标准、工具书或论文。 | 回到文件接收和 OA 拆解，重新扫描正文证据。 |
| HG-12 | 审查员对从属权利要求或非独立项给出具体证据或具体认定，答复稿仅写“独立权利要求具备创造性，故从属项也具备创造性”。 | 回到 claim chart 和答复稿审查，逐项回应该具体证据。 |
| HG-13 | 关键数学式、化学式、表格、附图或带格式限定在文件抽取后丢失，仍继续作确定性分析。 | 回到文件读取，使用渲染图、原 DOCX/PDF 或人工核对方式补齐。 |

# 降级规则

- 关键文件未齐时，可以输出“初步分析”，不得输出确定性结论。
- 法域未确认时，可以输出通用风险提示，不得引用具体程序路径作为最终建议。
- 对比文件未读全文时，可以整理审查意见逻辑，不得断言对比文件未公开某特征。
- 审查员补充引证文件未读全文时，可以标记其用途和风险，不得最终断言该证据不能支持常规技术手段。
- 支持位置未找到时，可以列为候选修改点，不得写入推荐权利要求修改方案。
- 已被审查员反驳的论点未经重构时，不得进入最终答复文本。

# 🔴 STOP / CHECKPOINT

最终文本生成前必须检查：

1. 是否存在审查员证据缺件；
2. 是否存在未核对的修改支持；
3. 是否存在未回应的独立权利要求或独立方法权利要求；
4. 是否存在已被审查员反驳但仍复用的论点；
5. 是否只从首页对比文件表提取证据而遗漏正文引证；
6. 是否存在从属项具体证据未回应；
7. 是否存在关键公式、表格或附图抽取丢失；
8. 是否存在最终稿新增核心论点。

任一项为“是”，不得输出“可提交版本”。只能输出“供代理人核对的草稿”或“审稿与修订建议”。

# 与领域评分标准的关系

完整领域评分见 `../docs/domain-rubric.md`。本 policy 只抽取执行中必须立即阻断或回退的 hard gate，不替代完整评分。


# 后续 OA 强风险检查

若 OA 是第二次或更后续审查意见，且正文出现“申请人的意见不具备说服力”“没有可以授予专利权的实质性内容”“不具备被授予专利权的前景”等强结论，必须执行以下检查：

| 检查项 | 要求 |
|---|---|
| 前次论点复用 | 建立“前次论点-审查员反驳-本次新基础”表；没有新基础的论点不得进入最终稿。 |
| 具体证据回应 | 对审查员在本次 OA 中新增或强调的每个证据用途逐项回应，不得只重复前次总论。 |
| 策略降级 | 若无新增限定、新证据或重构后的技术问题，输出级别不得高于“审稿与修订建议”。 |
| 复审准备 | 在策略报告中列出复审可保留论点、电话沟通问题和放弃/收窄边界。 |
