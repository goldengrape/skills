# 三类内容必须区分

## 事实

文件实际公开了什么。应引用：

- 说明书段落；
- 附图编号；
- 权利要求编号；
- 审查意见页码或段落；
- 对比文件段落或附图；
- 补充引证文件、教科书、工具书或标准的具体位置。

## 判断

是否构成区别特征、是否有技术启示、是否属于常规技术手段、是否足以支持审查员的组合逻辑。

## 策略

是否承认、反驳、修改、放弃、电话沟通或准备复审。

# 审查员证据缺件规则

若 OA 引用了对比文件、补充引证文件、教科书、工具书、标准或公知常识证据，而当前案卷未提供原文：

1. 必须列为“审查员证据缺件”；
2. 可以转述 OA 中的审查员观点，但置信等级只能为 B；
3. 不得把“未提供给当前模型”写成“审查员没有证据”；
4. 不得在最终答复草稿中确定性反驳该证据的公开内容；
5. 最终输出必须保留“待补证据清单”和“人工核对事项”。

# 已被审查员反驳论点规则

若 OA 已经对申请人前次答复中的某个论点作出明确反驳，后续答复不得机械复用该论点。必须建立下表：

| 原申请人论点 | 审查员反驳内容 | 当前答复是否复用 | 处理 |
|---|---|---|---|
|  |  | 是 / 否 / 部分 | 删除 / 改写 / 补证据 / 转为备选 |

只有在新增证据、新增权利要求限定或重新定义技术问题后，才可以改写后继续使用相关论点。

# 禁止做法

- 不得只根据审查意见转述对比文件；
- 不得把申请人想表达的效果当作说明书已经记载的效果；
- 不得把孤立特征的已知性直接等同于整体组合显而易见；
- 不得忽略审查员新增引证文件；
- 不得重复使用已被审查员反驳、且没有新证据或新限定支撑的论点；
- 不得把推断写成对比文件“明确公开”。

# 引用置信等级

每个关键事实应标注置信等级：

| 等级 | 含义 | 可用于什么 |
|---|---|---|
| A | 已直接读取原文并能定位段落、页码或附图。 | 可用于 claim chart、修改依据和最终意见陈述。 |
| B | 来自审查意见转述，尚未核对对比文件或补充证据原文。 | 只能用于 OA 拆解、风险识别和待核对清单，不得作为最终事实断言。 |
| C | 来自用户口述或代理稿，尚未核对案卷。 | 只能作为待核对事项。 |

# 强制回退

出现以下情况时，必须回到上游步骤修复：

- 对比文件未读，却判断某特征已公开或未公开；
- 审查员补充引证文件未读，却确定反驳其公开内容；
- 修改依据没有原申请支持位置；
- 当前答复复用已被审查员反驳的论点，且没有新增证据或新限定；
- 最终稿引用无法对应到文件；
- 事实、判断和策略写在同一句中，无法核对来源。

# 推荐引用格式

```text
说明书第[段落]记载……
对比文件1第[段落]仅公开……
审查意见第[页]将……认定为……
补充引证文件[公开号/名称]第[段落/页码]被审查员用于证明……，当前尚未核对原文。
```


# OA 正文证据扫描规则

文件接收和 OA 拆解不得只读取首页“对比文件”表。必须扫描 OA 正文中的以下证据标识，并全部加入“审查员证据清单”：

- 专利号、公开号、公告号；
- 论文、标准、教科书、工具书名称；
- “例如”“比如”“现有技术中”“公知常识”“常规技术手段”后列出的证据；
- 审查员用于证明某一从属项排列方式、尺寸范围、材料、工艺或函数选择属于常规设计的文件。

若首页写“未引用新的对比文件”，但正文用其他公开号证明常规技术手段，这些文件仍必须作为“正文补充引证”进入证据清单。不得因首页表格为空而忽略正文引证。


# 从属项具体证据规则

当审查员对从属权利要求或非独立项给出具体证据时，答复不得只写“独立权利要求具备创造性，因此从属项也具备创造性”。必须至少输出：

| 权利要求 | 审查员具体证据 | 该证据证明的内容 | 是否承认该内容 | 仍未公开或无启示的点 | 是否需要修改 |
|---|---|---|---|---|---|

若该表未完成，触发 HG-12，最终稿只能降级为“审稿与修订建议”。


# 复杂内容抽取规则

若权利要求、说明书或对比文件包含数学式、化学式、表格、附图或带上下标的参数，必须核对抽取结果是否完整。出现以下任一情况时触发 HG-13：

- DOCX/PDF 抽取后公式变成空白、分号或乱码；
- 图示关系被文字抽取遗漏，但审查员以附图作出“直接地、毫无疑义地得到”的认定；
- 表格参数、上下标或单位丢失，影响尺寸、范围或函数判断。

修复方式：使用原文件渲染页、截图、公式图片或人工核对结果补齐后，再进入 claim chart。
