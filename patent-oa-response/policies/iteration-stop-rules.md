# 默认限制

最多执行两轮完整迭代：

1. 当前候选 → 模拟 → 评估 → A/B 修订；
2. A/B 方案 → 二次模拟 → 二次评估 → 最终选择。

# 权责边界

- 修订步骤不得输出最终概率区间。
- 胜率区间只能由评估步骤输出。
- 胜率提升必须能够追溯到新增事实、新增限定、新证据或更强的对比文件反驳。
- 文字变顺、结构变长、语气变强，不得作为胜率提升依据。

# 允许继续的条件

继续迭代必须满足至少一个条件：

- 发现新的可加入权利要求限定；
- 发现新的说明书支持位置；
- 发现对比文件没有公开审查员认定的关键特征；
- 用户提供新的商业目标、实验数据或代理人意见；
- 审查员模拟暴露出此前未识别的失败路径。

# 不得提高胜率的情况

以下情况只能认为“文字改善”，不得提高授权概率区间：

- 表述更长但没有新增论证；
- 只是替换措辞；
- 仅重复已有技术效果；
- 没有新增权利要求限定；
- 没有新证据或新事实。

# 停止条件

出现以下任一情况时停止：

- 二次评估相对上一轮评估提升小于 5 个百分点；
- 进一步收窄会明显损害商业价值；
- 可修改特征池已用尽；
- 主要风险取决于审查员自由裁量；
- 领域质量守门触发 hard gate 且没有新增事实或修改依据可修复；
- 用户选择提交方案；
- 缺少关键文件，无法可靠继续评估。
