# 通用 OA Bundle 回归测试套件

## 1. 发布前结构检查

每次修改 bundle 后，至少检查：

1. JSON 文件可解析；
2. Markdown 相对链接无断链；
3. `policies/domain-quality-gates.md` 定义 HG-01 到 HG-13；
4. `skills/patent-final-response.md` 和 `templates/final-response.md` 覆盖 HG-01 到 HG-13；
5. `docs/domain-test-prompts.json` 不包含真实案号、客户名称、申请号、真实文件名或真实公开号；
6. 全 bundle 不包含真实案件材料或 回归样例。

## 2. 合成风险场景

| ID | 场景 | 必须触发或检查 |
|---|---|---|
| S-01 | 缺少说明书、附图或对比文件全文。 | 降级输出，不得生成可提交稿。 |
| S-02 | OA 首页证据表为空，但正文列出补充证据。 | 扫描正文补充引证并列入证据清单。 |
| S-03 | 二通中前次主要论点已被审查员反驳。 | 检查论点复用，要求新增限定、新证据或重构技术问题。 |
| S-04 | 从属项已有具体证据。 | 逐项回应从属项，不得笼统依附独权。 |
| S-05 | 权利要求含公式、附图标记、表格或单位。 | 执行复杂内容抽取核对。 |
| S-06 | A/B 方案只有措辞差异。 | 判定为无效 A/B，要求实质差异。 |
| S-07 | 最终稿新增未评估核心论点。 | 触发最终文本回退。 |

## 3. 隐私检查

发布前必须搜索并确认不存在：

- 真实公司名、申请人名、发明人名；
- 真实案号、申请号、内部编号；
- 真实 OA 日期和真实文件名；
- 真实对比文件公开号或公告号；
- 真实案件技术事实描述；
- 真实测试报告或回归样例文件。

如需保留真实案件回归，请使用独立私有测试包，不得并入通用 bundle。
