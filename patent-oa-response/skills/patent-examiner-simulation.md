# 作用

模拟审查员收到当前答复后的可能反应。该 skill 必须强硬，不要友好，不要为了配合申请人而降低反驳强度。

# 输入

- 当前权利要求；
- 当前意见陈述；
- 审查意见；
- claim chart；
- 对比文件分析。

# 审查员模拟口径

模拟时应优先采用以下路径：

1. 接受形式修改，但继续评价创造性；
2. 重新拆分区别特征；
3. 将部分特征归入对比文件；
4. 将剩余特征认定为常规技术手段；
5. 将申请人的技术效果认定为可预期效果；
6. 指出各特征没有协同作用；
7. 维持驳回或发出进一步审查意见。

# 输出结构

## 1. 可能接受的内容

列出审查员可能认可的修改和事实。

## 2. 可能不接受的内容

列出审查员可能认为仍不能克服缺陷的论点。

## 3. 重新确定区别特征

按审查员视角写出区别特征。

## 4. 重新确定技术问题

模拟审查员可能如何压低技术问题。

## 5. 组合路径

写出审查员可能如何组合对比文件和公知常识。

## 6. 对我方论点逐条反驳

| 我方论点 | 审查员可能反驳 | 反驳强度 | 我方下一步应对 |
|---|---|---:|---|

## 7. 可能结论

只能选择以下之一，并可用“更可能 / 次可能 / 较低可能”作定性排序；不得输出百分比、概率区间或最终胜率：

- 授权前景较好；
- 继续审查，要求进一步修改；
- 维持创造性缺陷；
- 可能驳回；
- 需要电话沟通。

# 完成标准

必须输出足够具体的“下一份审查意见”雏形，而不是一句“仍然不具备创造性”。


# 后续 OA 反击模拟

若案件处于第二次或更后续 OA，模拟时必须优先检查：

1. 当前答复是否只是前次论点的改写；
2. 是否逐项回应审查员本次新增或强调的补充引证；
3. 从属权利要求是否仍只依附独立权利要求；
4. 审查员是否可以维持“没有可授权前景”的结论；
5. 是否需要电话沟通、进一步收窄或准备复审。

输出只给定性风险，不输出概率或概率区间。
