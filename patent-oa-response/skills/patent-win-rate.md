# 作用

对当前答复候选进行现实评估。胜率只能用区间，不能给单点数字。

本 skill 是只读评估器：不得修改权利要求，不得生成新方案，不得把“表达更顺”当作胜率提高。

# 输入

- 当前答复候选；
- 模拟审查员意见；
- claim chart；
- 原申请事实底稿；
- 审查意见拆解；
- 客户策略偏好。

# 评估维度

| 维度 | 问题 |
|---|---|
| 授权概率 | 审查员接受当前候选的可能性 |
| 继续审查概率 | 是否更可能发三通、电话沟通或要求再改 |
| 驳回概率 | 是否可能直接维持缺陷并驳回 |
| 保护范围损失 | 修改是否牺牲核心商业价值 |
| 复审价值 | 驳回后是否仍有较好复审空间 |
| 稳定性风险 | 授权后是否容易被无效或规避 |
| 证据强度 | 是否有说明书、附图、实验数据或行业常识支撑 |

# 胜率区间规则

- 0%—20%：几乎无法克服，除非大幅修改或补证据；
- 20%—40%：有论点，但审查员组合路径较强；
- 40%—55%：有实质争取空间，但风险仍明显；
- 55%—70%：较有希望，通常需要权利要求收窄到强实施例；
- 70%—85%：较稳，但仍需核对修改支持和清楚性。

除非已有审查员明确表示可接受特定修改路径，否则不得输出高于 85% 的授权概率区间。

# 硬规则

- 没有新增事实、可加入特征或新论证路径时，不得上调胜率。
- 文字更流畅不等于胜率提高。
- 如果胜率提高来自收窄保护范围，必须明说牺牲了什么。
- 如输入未包含审查员模拟，必须先要求执行 [patent-examiner-simulation](patent-examiner-simulation.md)。
