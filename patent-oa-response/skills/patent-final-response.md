# 作用

把已选择方案整理成可交由专利代理人核对的最终答复草稿。

本 skill 只能整理已经过二次模拟和二次胜率评估的方案，不得新增未经评估的权利要求限定或创造性论点。

# 输入

- 已选择方案；
- 二次审查员模拟；
- 二次胜率评估；
- 原申请事实底稿；
- 审查意见拆解；
- claim chart；
- 人工核对要求；
- 领域质量守门结果；
- 审查员证据缺件清单；
- 已被审查员反驳论点检查表。

# 步骤

## 0. 核对领域质量守门

若 HG-01 到 HG-13 任一项触发，不得生成“可提交前草稿”。应说明触发项、证据来源和回退入口，并回到对应上游步骤修复。

可以输出的降级结果：

- 供代理人核对的草稿：存在轻微未核对事项，但不影响核心事实判断；
- 审稿与修订建议：存在审查员证据缺件、已反驳论点复用、方法项未回应等核心风险；
- 仅限待补证据清单：关键文件缺失，无法形成可靠草稿。

## 1. 整理质量守门摘要

最终文本前必须列出：

1. 关键文件是否齐全；
2. 审查员补充引证文件是否齐全；
3. 修改是否有原申请支持；
4. 所有拒绝理由是否回应；
5. 方法权利要求是否独立回应；
6. 引用是否可核对；
7. 是否复用已被审查员反驳的论点；
8. 未解决风险。

## 2. 整理修改说明

列出每个修改点、说明书依据、修改目的和风险。

## 3. 整理意见陈述

按以下结构输出：

1. 修改说明；
2. 与最接近现有技术的区别；
3. 实际解决的技术问题；
4. 对主对比文件的意见；
5. 对组合文件的意见；
6. 对公知常识或新增引证的意见；
7. 技术效果和显著进步；
8. 从属权利要求；
9. 方法权利要求；
10. 结论。

## 4. 整理方法权利要求独立论证

若存在独立方法权利要求，不得只写“装置权利要求具备创造性，因此方法权利要求也具备创造性”。必须说明：

- 方法步骤顺序；
- 工艺分工；
- 与装置结构的配合关系；
- 对成本、精度、效率或其他技术效果的贡献；
- D1/D2 或补充证据是否给出相同组合启示。

## 5. 整理提交前人工核对清单

至少包括：

- 修改是否超出原申请记载范围；
- 权利要求是否清楚、简洁；
- 是否引入必要技术特征缺失问题；
- 意见陈述是否与权利要求文字一致；
- 审查员补充引证文件是否补齐并核对；
- 已被审查员反驳的论点是否已删除或重构；
- 是否影响分案、侵权比对或商业保护；
- 是否遗漏同族、海外策略或客户商业目标。

# 输出结构

```markdown
## 输出级别

## 提交前质量守门摘要

## 最终答复草稿 / 审稿与修订建议

### 一、权利要求修改说明

### 二、修改依据

### 三、关于创造性

### 四、从属权利要求和方法权利要求

### 五、电话沟通建议，如需要

### 六、提交前人工核对清单

### 七、领域质量守门结果

### 八、剩余风险
```

# 完成标准

最终文本必须明确“供专业人员核对”，不得写成已经可以无条件提交的法律意见。最终草稿不得包含领域质量守门中未通过的事项。

# 🔴 STOP / CHECKPOINT

触发以下任一情况时停止生成完整意见陈述文本：

1. 审查员用于核心拒绝理由的补充引证文件缺失；
2. OA 正文补充引证尚未扫描或尚未进入证据清单；
3. 从属权利要求已有具体证据但未逐项回应；
4. 关键公式、图示、表格、单位或上下标参数未完成核对；
5. 关键修改缺少原申请支持；
6. 当前方案复用已被审查员明确反驳的论点；
7. 独立方法权利要求未单独回应；
8. 最终文本需要新增未经过模拟和评估的核心论点。

只有以上问题全部关闭，才能把输出级别提高到“可提交前草稿”。


# 最终文本禁止项

最终答复草稿不得包含以下内容：

- 未进入审查员证据清单的正文补充引证；
- 对从属项具体证据没有回应，却只写“从属项因引用独权而具备创造性”；
- 抽取失败的公式、图示或表格被当作已核对事实；
- 第二次或更后续 OA 中机械复用前次已被反驳论点；
- 未经二次模拟和胜率评估的新核心论点。

触发任一项时，输出级别必须降为“审稿与修订建议”或“供代理人核对的草稿”。
