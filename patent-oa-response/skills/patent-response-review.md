# 作用

已有代理答复稿时，先审稿，不急于重写。目标是判断该稿是否真正回应审查意见，并整理成后续模拟和评估可以读取的“当前答复候选”。

本 skill 不输出授权概率区间。授权概率只能由 [patent-win-rate](patent-win-rate.md) 在审查员模拟之后给出。

# 输入

- 原申请事实底稿；
- 审查意见拆解；
- claim chart；
- 已有代理答复稿；
- 前次答复和审查员对前次答复的回应，如有；
- 客户策略偏好，如有。

# 三轴审查

## 1. 法律轴

检查：

- 修改是否有说明书支持；
- 是否可能超范围；
- 权利要求是否清楚；
- 是否引入新的不必要限定；
- 从属项和方法项是否同步；
- 是否遗漏新颖性、创造性、支持或清楚性问题。

## 2. 技术轴

检查：

- 是否准确识别原发明；
- 区别特征是否完整；
- 技术问题是否过宽或过窄；
- 技术效果是否由区别特征产生；
- 是否误读对比文件；
- 是否遗漏审查员新增证据；
- 是否把推断写成对比文件明示事实。

## 3. 策略轴

检查：

- 是否过度承认审查员事实认定；
- 是否过度收窄保护范围；
- 是否适合电话沟通；
- 如果驳回，复审中是否还能继续打；
- 授权后是否容易被无效或规避。

# 已被反驳论点复用检查

若 OA 已对前次申请人意见作出回应，必须输出：

| 原申请人论点 | 审查员已反驳内容 | 当前答复是否重复 | 处理 |
|---|---|---|---|
|  |  | 是 / 否 / 部分 | 删除 / 改写 / 补证据 / 转为备选 |

处理原则：

- 没有新增证据、新增限定或新的技术问题定义时，不得把该论点放入当前答复候选；
- 可以保留为“历史论点”，但必须标注“不可直接复用”；
- 若决定改写，应说明改写后的新基础。

## 当前答复候选

后续模拟和评估只读取本节作为当前候选：

1. 当前权利要求修改；
2. 修改依据；
3. 创造性主线；
4. 对主对比文件的反驳；
5. 对组合文件的反驳；
6. 对公知常识或新增引证的反驳；
7. 从属项和方法项处理；
8. 已删除或弱化的历史论点；
9. 已知风险和未回应问题。

# 低证据模式

若审查员补充引证文件缺失，或前次答复全文缺失，本 skill 只能输出“审稿与修订建议”。不得整理为可直接进入最终文本的当前候选。

# 完成标准

必须指出：

1. 最值得保留的论点；
2. 最容易被审查员反击的论点；
3. 最应补充的权利要求限定；
4. 最应删除或弱化的说法；
5. 是否建议重写答复主线；
6. 是否存在已被审查员反驳但当前稿仍复用的论点。

不得输出百分比或概率区间。


# 从属项具体证据回应检查

若审查员针对从属权利要求给出具体证据、具体附图或具体常规技术手段认定，必须检查已有答复稿是否逐项回应。

| 权利要求 | 审查员具体证据 / 认定 | 答复稿是否回应 | 问题 | 处理 |
|---|---|---|---|---|
|  |  | 是 / 否 / 部分 |  | 补充逐项回应 / 修改权利要求 / 删除弱论点 |

若答复稿仅写“独立权利要求具备创造性，故从属项也具备创造性”，且审查员已经给出从属项具体证据，必须触发 HG-12。


# 正文补充引证回应检查

已有答复稿必须回应 OA 正文中用于证明常规技术手段或组合启示的补充引证。检查表：

| 补充引证 | 审查员用途 | 答复稿是否回应 | 是否只作总论 | 处理 |
|---|---|---|---|---|
|  |  | 是 / 否 / 部分 | 是 / 否 | 补充逐项回应 / 承认并转移主线 / 修改限定 |

未回应时，不得整理为“当前答复候选”；只能输出“审稿与修订建议”。
