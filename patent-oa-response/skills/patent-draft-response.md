# 作用

当用户没有提供已有答复稿时，生成初版答复候选，供后续审查员模拟和胜率评估使用。

本 skill 不输出授权概率区间。它只能比较路径的风险方向，不能替代 [patent-win-rate](patent-win-rate.md)。

# 输入

- 原申请事实底稿；
- 审查意见拆解；
- claim chart；
- 客户策略偏好。

# 步骤

## 1. 选择答复路径

至少比较三种路径：

| 路径 | 做法 | 保护范围 | 风险线索 | 适用场景 |
|---|---|---|---|---|
| 强辩 | 不修改或少修改 | 宽 | 高/中/低 |  |
| 平衡 | 适度收窄并强化论证 | 中 | 高/中/低 |  |
| 授权优先 | 收窄到说明书强实施例 | 窄 | 高/中/低 |  |

## 2. 草拟权利要求修改方案

每个新增特征必须列出：

- 原文依据；
- 加入目的；
- 对创造性的贡献；
- 对保护范围的影响；
- 是否可能引发清楚性、支持或必要技术特征问题。

## 3. 草拟意见陈述主线

包括：

1. 修改说明；
2. 区别特征；
3. 实际解决的技术问题；
4. 对主对比文件的反驳；
5. 对组合文件的反驳；
6. 对公知常识或新增引证的反驳；
7. 从属项和方法项；
8. 结论。

# 当前答复候选输出结构

后续模拟和评估只读取本节作为当前候选：

1. 推荐答复路径；
2. 权利要求修改建议；
3. 修改依据；
4. 创造性主线；
5. 意见陈述草稿；
6. 备选修改点；
7. 不建议采用的论点；
8. 已知风险和未回应问题。

# 完成标准

输出必须包括当前答复候选，但不得输出百分比或概率区间。
