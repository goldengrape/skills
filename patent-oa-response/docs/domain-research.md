# OA 答复 Skill 领域研究（通用版）

## 1. 研究目的

本文件为 OA 答复 skill 的领域评分和质量守门提供依据。它关注的是通用 OA 答复质量风险，不记录任何真实案件或历史测试样例。

## 2. 任务边界

OA 答复辅助流程至少包括：

1. 案卷完整性和法域确认；
2. 原申请事实底稿；
3. 审查意见拆解；
4. 权利要求要素映射；
5. 修改支持检查；
6. 新颖性、创造性、清楚性、支持等拒绝理由回应；
7. 审查员视角反驳；
8. 授权概率区间和风险条件；
9. A/B 修订方案；
10. 最终答复草稿或降级输出。

## 3. 高风险失败模式

| 风险 | 典型后果 | 对应防护 |
|---|---|---|
| 未读取关键文件就作确定判断。 | 虚构事实、错误让步、遗漏拒绝理由。 | 文件完整性检查、证据缺件降级。 |
| 只依赖审查意见转述，没有读取对比文件原文。 | Claim chart 不可复核。 | 证据位置、原文摘录和置信度列。 |
| 只看 OA 首页证据表，遗漏正文补充引证。 | 对“常规技术手段”“公知常识”证据回应不足。 | 正文补充引证扫描。 |
| 修改特征没有原申请支持。 | 引入超范围修改或支持不足风险。 | 修改支持表和 HG-02。 |
| 后续 OA 中机械复用已被审查员反驳的论点。 | 容易被维持驳回。 | 已反驳论点复用检查。 |
| 从属权利要求有具体证据但未逐项回应。 | 从属项答复空泛。 | 从属项具体证据回应表。 |
| 复杂内容抽取失败。 | 公式、图示、表格、单位丢失，导致技术特征误判。 | 复杂内容抽取检查。 |
| 胜率评估和方案生成互相循环。 | 自我强化，输出虚高。 | 胜率唯一出口和两轮迭代上限。 |
| 最终稿新增未经评估的核心论点。 | 最终文本与前序分析脱节。 | 最终质量守门。 |

## 4. 法域适配

通用版默认不强制绑定某一法域。执行时必须由用户或案卷确认法域和程序阶段。

- 中国案件：重点检查三步法创造性、修改超范围、清楚性、支持和必要技术特征。
- 美国案件：重点检查每个 rejection / objection / requirement 是否逐项回应，修改是否有 written description 支持。
- 欧洲案件：重点检查 problem-solution approach、added matter、clarity、unity 和程序阶段限制。
- 法域未确认时：不得输出具体程序路径作为最终建议。

## 5. 领域评分依据

领域评分应优先评价以下能力：

1. 能否建立可靠、可引用的事实底稿；
2. 能否逐项拆解 OA 拒绝理由；
3. 能否逐要素建立 claim chart；
4. 能否识别证据缺件和抽取失败；
5. 能否避免已反驳论点机械复用；
6. 能否提出有原申请支持的修改方案；
7. 能否把授权概率表达为条件区间；
8. 能否在 hard gate 触发时停止或降级输出。

## 6. 证据空白

本通用版保留以下谨慎限制：

- 未内置任何真实案件测试材料；
- 未宣称跨所有技术领域充分验证；
- 未内置 CN / US / EP 的完整官方条文库；
- 不替代执业专利代理师或律师的提交前判断。

## 7. 通用测试建议

为了避免引入真实案件隐私，发布版只保留合成测试场景。内部团队如需使用真实案件回归，应单独维护私有测试包，并在发布前再次执行隐私检查。
