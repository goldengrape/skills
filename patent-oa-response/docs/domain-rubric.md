# Domain Rubric：OA 答复 Skill 领域评分原则

## 1. 评分定位

本评分标准用于评价 OA 答复 bundle 的领域任务质量。公共评分检查文件结构、工作流和可执行性；本评分标准检查生成的 OA 分析、答复策略、修改方案和最终草稿是否专业、可核对、风险可控。

评分对象包括：

1. 案卷完整性检查；
2. 原申请事实底稿；
3. 审查意见拆解；
4. 权利要求与对比文件映射；
5. 当前答复候选；
6. 审查员模拟；
7. 授权概率区间和风险评估；
8. A/B 修改方案；
9. 最终答复草稿。

## 2. 计分方法

总分 100 分。每个维度按 1 到 10 分评分，再乘以权重。

```text
领域总分 = Σ（维度得分 / 10 × 维度权重）
```

每次评分必须记录：

- 评分依据；
- 证据来源；
- 主要扣分原因；
- hard gate 状态；
- 法域是否已确认。

## 3. Hard Gates

以下任一项触发时，领域评分不得高于 60 分；严重时直接判为不合格。

| ID | Hard Gate | 判定规则 |
|---|---|---|
| HG-01 | 未读文件却作确定性判断 | 未读取审查意见、权利要求、说明书或主要对比文件，却断言“已公开”“未公开”“具备创造性”等。 |
| HG-02 | 修改缺少原申请支持 | 提出权利要求修改，但未标注说明书、附图或原权利要求支持位置。 |
| HG-03 | 遗漏至少一个独立拒绝理由 | 对 OA 中任一独立拒绝、异议或形式缺陷未回应。 |
| HG-04 | 事实、判断、策略混杂 | 未区分文件公开内容、法律/技术判断和策略选择。 |
| HG-05 | 虚构引用或错误引用 | 编造段落号、页码、附图编号、对比文件内容或审查意见内容。 |
| HG-06 | 承诺授权结果 | 输出“必然授权”“一定撤销驳回”等确定性承诺。 |
| HG-07 | 自评循环 | 起草、审稿或 A/B 修订步骤自行给出最终胜率，绕过独立 win-rate 评估。 |
| HG-08 | 法域错配 | 中国案件套用美国程序路径，或美国案件套用中国三步法，且未说明限制。 |
| HG-09 | 最终稿新增未评估核心论点 | 最终答复文本中出现前面模拟、评估、选择阶段没有出现过的新核心限定或论点。 |
| HG-10 | 复用已被审查员反驳的论点 | OA 已经明确反驳申请人前次论点，后续答复在没有新增证据、新限定或新技术问题定义的情况下继续使用该论点。 |
| HG-11 | 遗漏 OA 正文补充引证 | 只读取首页对比文件表，遗漏正文中用于证明常规技术手段、公知常识或组合启示的公开号、标准、工具书或论文。 |
| HG-12 | 从属项具体证据未回应 | 审查员对从属项给出具体证据或具体认定，答复稿仅以独立权利要求具备创造性为由一笔带过。 |
| HG-13 | 关键公式/图示/表格抽取失败 | 关键数学式、附图或表格在抽取后丢失，仍继续作确定性分析或生成最终草稿。 |

## 4. 领域评分维度

| ID | 维度 | 权重 | 1 分锚点 | 5 分锚点 | 10 分锚点 |
|---|---:|---:|---|---|---|
| D1 | 案卷完整性与限制标注 | 10 | 不列文件清单，缺文件仍继续确定性分析。 | 列出文件，但缺少可继续/不可继续边界。 | 明确列出已读文件、缺失文件、版本、审查员补充引证文件、可分析范围和不能判断事项。 |
| D2 | 原申请事实底稿 | 10 | 只复述摘要或技术领域。 | 能说明发明点，但缺少权利要求层级和说明书支持点。 | 准确提取发明构思、权利要求结构、技术效果、可修改特征池和支持位置。 |
| D3 | OA 拒绝理由拆解 | 12 | 把 OA 当普通文本摘要。 | 能列出主要拒绝理由，但未拆清审查员逻辑。 | 逐项拆出拒绝类型、法条/规则、审查员认定、组合路径、区别特征、技术问题和公知常识认定。 |
| D4 | 对比文件与 claim chart | 14 | 未逐项比对权利要求要素。 | 有对比表，但混淆审查意见转述、对比文件原文和推断。 | 每个独立权利要求要素均映射到对比文件段落/附图，区分原文、审查员认定、明示/推断、置信度、可承认和不可承认内容。 |
| D5 | 修改方案合法性与支持 | 12 | 直接建议加特征，无支持依据。 | 有修改方向，但支持位置、清楚性或保护范围影响不足。 | 每个新增/调整限定都有原申请支持，说明是否影响清楚性、单一性、必要技术特征、保护范围和后续稳定性。 |
| D6 | 新颖性/创造性/清楚性论证质量 | 14 | 只说“不同”“有创造性”，没有推理。 | 有区别特征和技术效果，但技术问题或技术启示分析不稳。 | 围绕区别特征、技术效果、实际解决的技术问题、现有技术启示进行可复核论证；清楚性和支持问题也按对应逻辑处理。 |
| D7 | 策略质量 | 10 | 只追求授权，随意大幅收窄。 | 能给出策略，但保护范围、复审价值或商业目标分析不足。 | 同时比较授权概率、保护范围损失、审查员接受可能性、复审价值、授权后稳定性和客户策略偏好。 |
| D8 | 审查员模拟与风险评估独立性 | 8 | 模拟只重复我方观点。 | 能提出部分反驳，但没有形成下一轮 OA 视角。 | 从审查员角度给出可能维持理由、新增组合、已被反驳论点复用风险、可接受修改、不可接受点，并由独立评估步骤输出胜率区间。 |
| D9 | A/B 方案差异与选择 | 6 | A/B 只是措辞不同。 | A/B 有差异，但没有明确适用场景。 | A/B 在权利要求限定或论证路径上有实质差异，并说明授权优先、范围平衡、不推荐方案及适用条件。 |
| D10 | 最终文本可用性与人工核对 | 4 | 最终稿像分析笔记，不能交给代理人核对。 | 有答复文本，但质量守门摘要、修改说明、引用或核对清单不足。 | 输出接近正式答复结构：质量守门摘要、修改说明、意见陈述、逐项回应、引用、剩余风险、提交前人工核对清单齐全；缺件时自动降级。 |

## 5. 推荐等级

| 分数 | 等级 | 含义 |
|---:|---|---|
| 90–100 | A | 可作为高质量辅助草稿，仍需代理师最终核对。 |
| 80–89 | B | 可用于策略讨论和初稿整理，局部需人工补强。 |
| 70–79 | C | 有参考价值，但不能直接进入最终答复草稿。 |
| 60–69 | D | 只能作为粗分析，需重新做 claim chart 或修改支持检查。 |
| < 60 | F | 不合格，应回到案卷读取或 OA 拆解阶段重做。 |

## 6. 法域适配原则

默认法域应由用户或案卷确定。未确定时，skill 必须标注“法域未确认”。

### 中国案件

重点检查：

- 是否按中国专利审查实践处理新颖性、创造性、清楚性、支持、修改超范围；
- 创造性分析是否围绕最接近现有技术、区别特征、技术效果、实际解决的技术问题和技术启示；
- 是否避免把技术启示直接写进技术问题；
- 是否检查新增特征对技术问题解决是否有贡献；
- 是否提示复审、电话沟通、继续修改的适用条件；
- 是否把审查员补充引证文件单独列出并核对；
- 是否扫描 OA 正文中被用于证明常规技术手段的补充引证；
- 是否逐项回应从属权利要求中的具体证据；
- 是否对关键公式、附图和表格进行抽取完整性核对；
- 是否对独立方法权利要求进行步骤、工艺分工和协同效果分析。

### 美国案件

重点检查：

- 是否回应每个 rejection、objection 或 requirement；
- 是否具体指出 examiner error 和 claim distinctions；
- amendment 是否存在 written description 或 new matter 风险；
- after-final、RCE、appeal 等路径是否被正确区分。

### 未配置法域

未配置法域时，领域评分最高不得超过 85 分；若输出中使用具体法条、审查指南章节或程序路径，但未确认法域，最高不得超过 70 分。

## 7. 常见扣分项

| 问题 | 扣分建议 |
|---|---:|
| 只根据 OA 转述对比文件，没有读取对比文件原文。 | D4 扣 4–8 分；严重时触发 HG-01。 |
| 把“说明书想表达的效果”当作“说明书已经记载的效果”。 | D2、D6 各扣 2–4 分。 |
| 修改特征没有支持位置。 | D5 扣 5–10 分；严重时触发 HG-02。 |
| 创造性论证只写“没有技术启示”，但不说明为什么。 | D6 扣 3–6 分。 |
| A/B 方案只是语气不同。 | D9 扣 4–6 分。 |
| 胜率给单点数字，如“73%”。 | D8 扣 2–4 分。 |
| 最终稿新增未经评估的论点。 | D10 扣 2–4 分；严重时触发 HG-09。 |
| OA 已反驳前次论点，后续答复仍机械复用。 | D8、D10 各扣 3–6 分；严重时触发 HG-10。 |
| 只读取首页对比文件表，遗漏正文补充引证。 | D1、D3、D4、D6 扣分；严重时触发 HG-11。 |
| 审查员补充引证文件缺失，但最终稿仍确定性反驳常规技术手段。 | D1、D4、D6、D10 扣分；严重时触发 HG-01/HG-05。 |
| 从属项已有具体证据，答复仍只依附独立权利要求。 | D6、D8、D10 各扣 2–5 分；严重时触发 HG-12。 |
| 公式、图示、表格抽取不完整仍继续判断。 | D1、D2、D4、D10 扣分；严重时触发 HG-13。 |
| 独立方法权利要求只依附装置项，没有单独论证。 | D6、D7、D10 各扣 2–4 分。 |
| 没有人工核对提示。 | D10 扣 2–4 分。 |

## 8. 使用方式

本评分标准用于两个位置：

1. Darwin 优化 bundle 时，作为领域评分依据；
2. OA bundle 执行时，在最终草稿前作为质量守门清单。

执行中若触发 hard gate，应回到对应上游步骤修复，不得直接生成最终草稿。
