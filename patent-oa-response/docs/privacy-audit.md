# Privacy Audit：通用 OA Bundle

## 1. 检查目标

确认通用发布版不包含用户提供的真实案件材料，也不包含可识别真实案件的直接标识。

## 2. 已执行的脱敏动作

- 删除真实案件测试报告；
- 删除真实回归样例文件；
- 删除指向真实案件测试的索引、日志和追踪条目；
- 删除真实案号、申请号、客户/申请人名称、真实文件名；
- 删除真实对比文件公开号或公告号；
- 将测试要求改写为合成风险场景；
- 将领域研究和评分元数据改写为通用版。

## 3. 自动搜索检查

已对 bundle 文本执行敏感残留搜索。检查类别包括：

- 真实客户或申请人名称；
- 真实内部案号；
- 真实申请号；
- 真实文件名；
- 真实对比文件公开号或公告号；
- 具体技术领域案件事实；
- 真实测试报告文件名；
- 真实回归样例文件名。

结果：未发现上述真实案件信息残留。

## 4. 保留内容说明

通用版仍保留以下抽象规则，因为它们不指向具体案件：

- 审查员正文补充引证扫描；
- 证据缺件降级输出；
- 已反驳论点复用检查；
- 从属项具体证据回应；
- 复杂内容抽取检查；
- HG-01 到 HG-13 质量守门。

## 5. 后续要求

如后续再次使用真实案件做回归测试，应将测试材料放在私有目录，不得写入通用 bundle。发布前必须重新执行本隐私检查。
