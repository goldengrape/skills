# 目标

通过有限迭代提高答复质量，同时避免模型自我循环。

# 默认循环

最多两轮：

1. 当前答复候选 → 模拟审查员 → 胜率评估 → A/B 修订；
2. A/B 方案 → 二次模拟 → 二次胜率评估 → 最终选择。

# 权责边界

- 模拟步骤只输出审查员可能如何反驳。
- 评估步骤只输出概率区间和风险。
- 修订步骤只输出 A/B 方案，不自行给最终概率。
- 最终选择只能依据二次模拟、二次评估和领域质量守门结果。

# 允许继续迭代的条件

只有出现以下至少一种情况，才允许继续：

- 发现新的说明书支持特征；
- 发现对比文件存在新的未公开要素；
- 审查员模拟暴露出新的失败路径；
- 用户改变策略偏好；
- 有新的实验数据、补充证据或商业保护目标。

# 不允许继续迭代的情况

- 只是把意见陈述写得更长；
- 只是换说法，没有新增论点；
- 胜率提升来自模型自我认可，而非新增依据；
- 进一步收窄会明显损害商业价值；
- 当前主要风险已属于审查员自由裁量。

# 终止输出

当停止迭代时，输出：

- 当前最佳方案；
- 停止原因；
- 剩余风险；
- 提交前人工核对清单。
