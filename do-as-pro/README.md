# Do as Pro Skill v0.2

`do-as-pro` 是一个独立、自包含的通用 skill，用于帮助非专家在陌生领域中，按照专业人士的方式完成任务。

它的核心入口是 **AI 辅助的专业重构**：AI先把用户的自然目标转换成合适的专业任务模型，补出专业标准、必要维度、常见错误和验证方式；随后再以小步、可检查、可修订的方式完成成果。

## 独立性

本技能包没有其他 skill 依赖，也不要求共享运行契约、路由 skill 或外部模板库。

它可以按任务需要调用搜索、文件、代码、计算、连接器或其他可用工具，也可以要求合格的真人专家复核；这些属于证据和执行资源，不是运行本 skill 的前置依赖。

即使只加载 `SKILL.md`，也可以运行核心流程。`references/` 和 `evals/` 是包内辅助资料。

## 文件

- `SKILL.md`：完整运行规则、状态流程、风险控制和单文件回退模板。
- `references/compact-run.md`：低风险任务的轻量试跑流程。
- `references/output-templates.md`：规格、未知、假设、缺陷、偏离、实验、修订和交付模板。
- `references/design-rationale.md`：设计理由与边界。
- `evals/EVALS.md`：检查通用回答退化、错误模型和流程膨胀的测试案例。

## 适用情境

适合以下任务：

- 用户知道现实目标，但不知道专业上应如何定义；
- 用户不知道专业人士通常会检查什么；
- AI容易给出宽泛、折中、缺少判断的回答；
- 成果需要明确依据、假设、不确定性和验证路径；
- 需要把经验判断改写成可检验假设或最小实验。

不应仅因为任务很长就使用。用户已经提供了完整专业规格、只需要机械执行时，可直接执行；除非还需要专业模型复查、外部校准或风险控制。

## 核心流程

```text
自然目标
→ AI辅助专业重构
→ 高信息量情境校正
→ 当前专业规格
→ 专业模型校验
→ 最小可验证增量
→ 执行
→ 内部检查
→ 外部校准或最小实验
→ 定向修订
→ 带边界交付
```

## 推荐试跑

先选择一个低风险、可撤销的真实任务，观察它是否：

1. 明确选择了一个主要专业任务模型；
2. 没有把完整需求定义推回给用户；
3. 只询问真正会改变方法的问题；
4. 区分了事实、假设、推断、估计和偏好；
5. 选出了能尽快暴露错误理解的首个增量；
6. 能区分执行缺陷、规格缺陷和专业模型缺陷；
7. 没有为了显得严谨而无限增加步骤。
