# Compact Run Protocol

Use this protocol for low-risk tasks or early trials.

## Step 1 — Reframe

Return five compact sections:

1. **专业任务判断** — what the task is professionally called.
2. **为什么这样判断** — why this archetype is primary.
3. **不可省略的维度** — the minimum expert dimensions.
4. **真正需要用户回答的问题** — no more than three, only when material.
5. **暂定默认值** — explicit defaults for everything else.

## Step 2 — Specify

Create a short current specification:

- goal;
- method;
- deliverable;
- acceptance criteria;
- assumptions;
- unknowns;
- risk level.

## Step 3 — Produce one increment

Choose a small result that is both useful and diagnostic. Do not create the whole project unless the task is already well specified and low risk.

## Step 4 — Review and calibrate

Check:

- one internal defect pass;
- one external comparison or deterministic verification;
- one question asking what evidence would overturn the main conclusion.

## Step 5 — Decide

Return one status:

- `usable_now`
- `revise_locally`
- `reframe_task`
- `needs_external_fact`
- `needs_experiment`
- `needs_human_review`
